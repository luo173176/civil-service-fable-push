# 粮仓里的钥匙

## 寓言故事

民国二十三年，柳河镇积谷仓设在旧祠堂里，青砖墙上一道石灰刷的“丰”字。仓里八百石稻谷，是全镇四百户人家按亩摊派、一季一季凑起来的备荒粮。管仓员周德昌吃住都在后厢，月薪四块大洋，是镇公所里最不起眼的差事。

规矩刻在木牌上：开仓须镇长、乡绅代表、管仓员三人验封，出入仓当日登簿，每月十五晒粮验数。

头一任管仓员姓吴，干了三年，逢年过节把验封的乡绅请到家中吃饭，桌上摆新米鲜鱼。第三年镇公所议起“粮仓每年损耗过大”，要裁一个人，裁掉的是提议清查账目那位乡绅推荐的年轻人。吴管仓留了下来。

周德昌不爱说话，很会做事。镇长母亲咳喘，他托人从县城捎来陈皮与川贝，说是亲戚的方子。乡绅代表的儿子在省城读书，学费周转不开，他从自家柜里递出二十块大洋，借据都没打：“不急，什么时候宽裕了再说。”

验封那天，他总把账本摊得平平整整，请两位先看。粮囤一开，热气扑脸，他站在旁边递斗递笔，从不多话。日子一长，镇长和乡绅代表懒得下祠堂，只问一句：“德昌，数对吗？”他答一句：“对得上，籴进粜出都记得清清楚楚。”验封便成了盖章，章一盖，各自散了。

仓里的粮，确实少了。起初是耗损，潮湿发霉，鼠咬虫蛀；后来是借，镇长姻亲的铺子急周转，从仓里抬走二十石，白条压在德昌枕下；再后来是“民借”，镇上几户大户按七折从仓里籴走新谷，秋后按市价卖回镇民。德昌一分不揣自己腰包，账上每笔有字，每次开仓有章。

他还有一件本事：镇民来问存粮，他翻得出最细的账，“你户上年纳了两石三斗，余账一分不少。”来人满意地走。若有人真要查总数，他便把三五年前的旧账抱出来，从纳粮的秤说起，一桩一笔讲到天黑。镇民听着听着就困了，说声“德昌你辛苦”便走。

第四年秋，邻县闹灾，省里派人来查积谷。查账的科员在祠堂坐了一日，德昌陪了一日，泡茶、点烟、递账本。科员临走时感慨：“这样的账，这样细心的人，如今少见。”

灾荒终于来了。镇民扛着箩筐来开仓，仓里只剩二百一十石。德昌站在门口，声音发颤：“耗损，这些年耗损大。”

有人不依，撬开后厢，翻出枕下白条三十七张，大半是镇长的姻亲，其余几户，都是每年替德昌在镇长面前说过话的。镇上炸开了锅，嚷了三天，嚷不出名目：白条上有借有还的细则，有镇长的印，有乡绅代表的章，哪一条都挑不出一个“偷”字。

镇长在祠堂前请全镇人吃了一场茶，说：“德昌管仓四年，账目清楚，人情厚道，如今遭人误会，我替他担保。”乡绅代表坐在旁边，抽着烟，点点头。

周德昌没被追究。他只是把钥匙擦了擦，重新挂回腰上，接着吃住在那座祠堂后厢里。新木牌照旧钉在墙上，只是“每月十五晒粮验数”那一行，换成了“每季由镇长审阅”。

镇里人议论了几日，也就散了。有人路过祠堂，看见那扇门还开着，德昌坐在门槛上，见人来了，起身招呼一声：“进来坐，喝口茶。”他腰间的钥匙碰着门框，晃了一下，没响。

## 原来讲的是……

**概念：规制俘获**

多年以后，镇志修成，有一页写积谷仓的存废，末一句是：“积谷之政，本以御荒，终以荒废，非无守者，守者久守，遂与仓中人共食其谷。”编写镇志的老人姓柳，那年十六岁，见过德昌泡茶的手，也见过他腰上的钥匙。文中他没写周德昌的名字，只写“守者”。有人问他：“守者到底是好人还是坏人？”柳老人想了一会儿，说：“他大概真的以为自己在守仓。钥匙挂在身上久了，人就不觉得门是别人的了。”

原来讲的是——规制俘获。

## 概念解释

规制俘获（regulatory capture）是政治学、行政法学与规制经济学共同关注的经典命题。它的基本含义是：本应作为“守夜人”的政府规制机构，在实践中可能逐渐转向为被规制行业的利益服务。斯蒂格勒（George Stigler）1971 年在《经济规制论》中提出了对“规制为公共利益服务”这一流行假设的反对结论：规制往往是被产业“购买”的产品。佩尔兹曼（Samuel Peltzman）1976 年进一步用模型说明，规制者追求政治支持最大化，最优规制通常更偏向组织良好的小集团。两人合起来，形成了需求侧的解释：产业对规制有需求，政治供给者愿意出售，价格是选票、资金、职位与信息。

理解这一概念需要把握若干关键条件。其一，规制者存在自身利益——机构的预算、编制、政绩、个人未来的职业去向，未必与“公共利益”完全重合。其二，需求方的组织化程度明显高于受益方。少数几家企业有共同利益、稳定的组织、明确的诉求，而分散的消费者人数虽多、人均损失却小，搭便车者比比皆是。奥尔森的集体行动逻辑在此起作用：集中利益比分散利益更容易组织。其三，信息不对称。规制机构需要行业数据、技术标准、专业判断，而最了解情况的人恰好是被规制者本人。规制者长期依赖被规制者提供事实，便不自觉地用对方的眼睛看问题。其四，“旋转门”：监管者与被监管者之间的人员流动——离任官员进入企业，从业人员被提拔到监管机构——会制造稳定的预期与默契，使规制者自觉不做出“过于得罪行业”的决策。其五，俘获不等于贪腐。这是最常被误解的一点：它多数时候是合法的、无形的，不需要现金交易，一次会议、一场联谊、一份数据、一条推荐、一句“他很懂行”，都可以是通道。俘获的关键不是有没有违法行为，而是规制者是否还代表其本该代表的利益。

在公共管理与公务员考试语境中，规制俘获提供了一套分析“监管失灵”的框架。传统思路倾向于说“监管不到位”就加强监管，规制俘获理论则指出，监管失灵有时恰恰因为监管者与被监管对象已经融为一体，单纯加码监管反而可能强化二者的合作。中国近年推进的中央环保督察、国家反垄断局组建、金融监管机构党组织关系调整、监管者与被监管者之间的任职回避与离职从业限制，都是从这个角度出发、拆除“旋转门”、把信息渠道重新拉回公共视野的制度努力。

现实案例至少可以举两个。第一，2008 年全球金融危机前，美国证券交易委员会与华尔街之间的密切人员往来长期被研究者关注；危机后的多德-弗兰克法案，专门限制金融机构高管与监管者的往来与离职去向。第二，中国 2020 年以来对互联网平台反垄断的推进，正是在平台企业掌握大量行业数据、并提前塑造行业标准与“自我规制”话语的背景下，通过成立专门机构、调整监管口径，重新夺回分析能力的尝试。金融监管领域历史上也曾出现机构人员与被监管机构之间的人事关联问题，此后监管体制在组织关系与人员回避上进行了系统改革。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 积谷仓与守仓员 | 规制机构与规制者 | 本应代全体镇民看守公共资源，却被设定为“守夜人”的角色 |
| 镇民分散纳粮、少有人查账 | 分散的消费者与纳税人群 | 每人损失小、监督成本高，构成集体行动困境 |
| 镇长与乡绅代表验封盖章 | 形式化的行政监督 | 监督流于形式，盖章成为规制者与行业之间的仪式 |
| 陈皮、川贝、二十块大洋 | 合法的人情往来与利益输送 | 不是贿赂，是能让人“不好意思”对对方下手的软性投资 |
| 白条与七折籴谷的大户 | 被规制行业的少数集中利益者 | 数量少、组织好、可直接获益，构成稳定的需求方 |
| 德昌详细讲账、把人讲困 | 信息俘获 | 只有被规制者掌握最完整信息，监督者无从判断真伪 |
| 省里科员夸“这样的账如今少见” | 上级检查的失效 | 检查依赖被检查者提供的材料，形成“合格证明”的循环 |
| 灾荒时只剩二百一十石 | 规制失败的最终后果 | 风险爆发时才暴露问题，损失由公众承担 |
| 白条逐条挑不出“偷”字 | 俘获的合法性外形 | 有手续、有章、有细则，因此难以追究贪腐责任 |
| 钥匙挂在腰上、碰门框不响 | 制度通道的日常化 | 俘获不是一次事件，而是长期结构，钥匙就是“旋转门” |

## 公务员考试视角

行测常识可能以“规制俘获理论的提出者”“与公共选择理论的关系”“俘获区别于贪腐之处”作为选项设计，注意斯蒂格勒与佩尔兹曼的区分，以及“集中利益对分散利益”这一核心判断；申论材料若涉及反垄断、平台监管、金融监管、行业协会与主管部门关系、政企“亲清”边界，可用规制俘获作为分析框架，从信息、组织、人员流动与合法性四个维度找原因，而不是简单归结为“监管力度不够”；结构化面试中，遇到“监管者与被监管者关系密切”“行业标准为何由龙头企业主导”“离职官员进入企业”等情景，可先指出问题的结构性与合法性外观，再谈回避制度、信息渠道多元化与独立机构建设。

## 思考题

1. 周德昌四年里一分钱没进自己腰包，账上有字、开仓有章。如果他仍然使镇民失去了五百多石粮，那“守者”与“盗者”的区别到底在哪里？
2. 镇民来问存粮时，德昌“翻得出最细的账”。为什么最详细的账反而挡住了监督？如果换成省里科员，他需要什么样的外部信息才能发现真相？
3. 结尾柳老人说“钥匙挂在身上久了，人就不觉得门是别人的了”。新木牌把“每月十五验数”改成“每季由镇长审阅”，这一步是修复了监管，还是把制度层面的配合推得更远了？
