# 井口的木牌

## 寓言故事

开春没下一场透雨。县里下来的文书上写着：保苗水，三日一浇，不得有误。

乡里开会，乡长把那张纸抖了抖：“三日一浇是底线。咱们乡要争先进，两日一浇。哪块地断了水，村主任自己来乡里说。”

村长周德海骑车子回柳树沟，一路上把“两日”在心里盘成了“一日”——乡里比县里紧一天，村里就得比乡里再紧一天，不然检查一来，先扣的是柳树沟。当晚他在井台边开会，说：“从明早起，一日一浇。”

井台上只有一口井，一台抽水机，柴油按户摊。管井的老柳头六十三了，管了三十年井，负责在一块木牌上记水：哪天浇的、几亩、几遍。

头三天，全村人熬在地里。第四天，抽水机烧了皮带。第五天，井底开始返沙。

周德海把老柳头叫到村部：“牌上记了多少？”

“四十七亩，一日一遍。剩下的排到后天。”

“全村春苗二百一十亩。”

“水就这么多。”

“数得对得上。”

老柳头听懂了。他没吭声。回去以后，他把井壁上的水痕刻记往下挪了半尺。那是几十年攒下的老刻痕，一道一道，记着哪年旱、哪年涝。挪完之后，井水还是那些井水，可拿尺子一量，水位高出一截。乡里来人量过一回，在本子上记了，临走站在井台边说：“柳树沟的井，比乡里估的强。”

木牌上的亩数一天天涨。二百一十亩，一日一浇，成灾零亩。老柳头每天蹲在井台边写，字写得横平竖直。

夏末检查，县里来看材料。检查团在村部墙上看了表格，红笔画的圈一个不少，又到井台上拍了照。周德海那年评了先进，奖下来一台喷灌机。喷灌机没水，搁在村部后头，落了灰。

秋收算账，柳树沟亩产比前年少了四成。没有人问。报表上写的是“因旱略减，总体平稳”。

入冬，老柳头把刻痕挪了回去。挪的时候被周德海撞见。两个人在井台上站了很久。风从塬上刮下来，井绳撞着辘轳，一下，一下。

最后周德海说：“我也只是转述上面的话。”

老柳头问：“那上面转述的是谁的？”

周德海没答上来。

这话在他心里存了二十年。二十年后孙子考进县里，头一年下乡核查种粮面积，回来跟他抱怨：“爷爷，报上来的数，没一个是准的。”

周德海蹲在灶前添了一把柴，火光跳了跳。

“井绳上串着一排水桶，”他说，“你问哪一只，哪一只都说自己只是把话往下转。转到最后那一只，桶里的水洒了一半，账上写的还是满的。”

孙子抬起头。周德海把火钳往灶膛里一插，没再说话。

## 原来讲的是……

**概念：压力型体制**

## 概念解释

**定义与关键条件**

压力型体制，指上级把经济社会发展的任务拆成可计量的指标，逐级分解下达到下级，并配套目标责任制、量化考核、排名通报和“一票否决”等硬约束；下级在权限与资源并未同步增加的情况下，必须按期完成并接受奖惩，于是每一级都想在上级要求之外再留一点“安全边际”，任务在传导中被逐级放大。荣敬本等人把它概括为“加压—分解—考核—反馈”的运行方式。

它成立需要几个条件：目标能被数字化拆解（亩数、增幅、排位、销号数）；上级掌握考核权与人事权；事权下沉而财权、编制、审批权上收；存在若干刚性否决项，任一项不达标即全盘否定；任期短、考核频，形成时间上的挤压。这五条同时具备，压力才传得下去；缺一条，压力就会在中途卸掉。

**学术背景与提出者**

这一概念出自 1990 年代中期中央编译局荣敬本、崔之元等学者对河南新密等县乡的实地调查，成果是《从压力型体制向民主合作体制的转变——县乡两级政治体制改革》（1998）。此后何增科、杨雪冬等人继续推进，杨雪冬把它用于解释县乡两级的行为逻辑；周雪光的“共谋现象”“运动型治理”、周黎安的“行政发包制”，则是与之对话、互补的另一组解释工具。

需要避免一个常见误解：压力型体制不是科层制本身，而是中国科层体系的一种动力机制。科层制讲的是分工、层级与规则；压力型体制讲的是这套层级靠什么被驱动起来。它也不天然是贬义——脱贫攻坚、重大工程、突发公共卫生事件初期的动员能力，很大程度上正来自这种自上而下的压力传导。问题出在压力超出资源与制度承载能力的时候：指标硬、资源软，中间那一层就只能用“材料”和“数字”去填。

它的另一个特征是，它与运动式治理互为表里：平时靠指标驱动，非常时期靠集中整治加码，整治结束后指标又留下，层层叠加，基层负担由此累积。所以“痕迹主义”“表格扶贫”“一刀切”这些现象，若只在作风层面找原因，往往找不到根；往上一层看，是考核结构在起作用。

**在公共管理与公务员考试中的意义**

它为基层治理现象提供了“制度解释”这一层。申论材料里给出一堆填表、留痕、迎检的细节，如果只答“干部作风不实”，得分有限；指出“指标单一化、考核频次过高、责任与资源不匹配”，再提出“指标设置留出协商空间、考核从材料转向群众评价、清理否决项”，才是结构性的答法。

**现实案例**

其一，2018 年生态环境部通报的山西临汾大气环境质量监测数据造假案。空气质量改善指标自省到市、自市到县层层加码，考核排名又与主要负责人前途直接挂钩，最终压力传导到最末端的采样环节，监测设施被人为干扰，多名责任人被追究刑事责任。指标“完成”了，空气没有变好——这正是末端用改度量代替改实质的典型。

其二，脱贫攻坚中的“算账式脱贫”与填表报数。收入核算被拆成一栏栏数字，帮扶干部按栏填报、按栏迎检，部分地方出现“数字达标、实际未稳”。2019 年被确定为“基层减负年”，2024 年中办、国办印发《整治形式主义为基层减负若干规定》，直接针对指标层层加码、督查检查过多过频、以留痕代替落实。这些文件的靶子，正是压力型体制在基层的负外部性。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 县里文书“三日一浇” | 上级下达的原始任务指标 | 压力的起点，本身是可完成的 |
| 乡长改“两日”、村长改“一日” | 指标逐级加码 | 每级为免于问责预留安全边际，“县里 110，乡里 120，村里 130” |
| 一口井、一台抽水机、柴油按户摊 | 事权下沉而资源未同步下沉 | 硬指标与软资源的夹缝，是策略性应对的土壤 |
| 木牌上的亩数、墙上的红圈表格 | 数字化考核与材料政绩 | 可核查的数字取代了难以核查的效果 |
| 老柳头把井壁刻痕下挪半尺 | 策略性应对与数据失真 | 不改水，只改度量；成本最低、见效最快 |
| 检查团量水位、拍照、评先进 | 考核评比与激励扭曲 | 核查依赖被考核者提供的度量，闭环失效 |
| 亩产减四成无人问，报表写“总体平稳” | 信息失真与反馈失灵 | 上报链条自我美化，纠错信号被过滤掉 |
| 周德海“我只是转述上面的话” | 责任层层下推、责任稀释 | 每一级都自认是执行者，无人认领决策责任 |
| 井绳串水桶、水洒一半账上仍满 | 压力传导中的失真累积 | 概念的核心意象：转述者众多，损耗无人核算 |
| 孙子下乡核查面积，发现数都不准 | 机制的再生产 | 换了一代人、换了一套表，运行逻辑未变 |

## 公务员考试视角

行测常识（管理类）可能直接考概念的提出者与出处，或让考生辨析“压力型体制”与“科层制”“运动式治理”“行政发包制”的差别——记住它是动力机制，不是组织结构。申论多给基层减负、形式主义、层层加码类材料，要求概括表现、分析原因、提出对策；原因部分若只写“作风不实”，层次偏浅，应写出“考核指标单一化、责任与资源不匹配、否决项过多、督查重痕不重绩”，对策才能落到指标设置、考核方式、容错与资源保障上。结构化面试常以“领导把任务压给你、下级又完不成”的情境题出现，答题时应体现两头兼顾：对上如实报告资源缺口，对下不搞二次加码，用可分步、可协商的指标替代一次性摊派。

## 思考题

1. 乡长把“三日”改成“两日”，周德海又把“两日”盘成“一日”。这两次加码，各自在防什么风险？如果周德海照抄“三日”，他在乡里的处境会怎样？
2. 老柳头挪动的是井壁上的刻痕，而不是井水。为什么“改刻度”比“改水”更容易被各方接受？检查团量了水位、拍了照、评了先进——这条链上哪一环本来可以发现刻度被动过？
3. 二十年后孙子说“报上来的数，没一个是准的”。如果他要在自己负责的那次核查里做一点改变，他手上的空间在哪里？他改动之后，会得罪链条上的哪一节？
