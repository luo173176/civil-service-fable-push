# 四样东西赶上同一天

## 寓言故事

烂板桥在十六铺码头西边，一块预制板搭在两道石阶上，走上去晃晃悠悠，名字就这么来的。逢农历三、六、九开市，卖什么的都有。

老蒯蹲在西头，面前摆一台抽水泵。泵是他自己配的：前年他想租村东的鱼塘，借钱买了柴油机，裁了管子，连叶轮都是托人从县里车出来的。结果鱼塘让村支书的外甥抢先租走了。泵闲置在屋里占地方，老婆天天骂。他扛到烂板桥，要价八百，心里六百也认。

白秀英从东头过来，已经跑了三趟。三号仓库进了水——不是雨水，是库底下的自来水管裂了。她是仓库管账的，一个月一百二。主任去地区开会，走了七天。她找装卸队，人家说抽水加钱三百；找公司总务，总务说买水泵得打报告，报告要主任签字。水一天涨一寸，泡着二十吨白糖。

阿茂是码头调度。他上衣口袋里有一张条子，四折，洗过三回，边角发毛。上头写着：三号仓库东西两侧的临时用电与场地使用，由阿茂现场处置。这是去年汛期发的，字还没褪。

三月初三，白秀英到烂板桥想找台泵。老蒯没来——老婆拉他去走亲戚。她只看见一个卖麻绳的老陈，蹲在中间抽烟。她空手回去了。

三月初六，老蒯来了，泵摆在西头，还写了块硬纸板：八百，可议。白秀英没来。主任回来了，她被叫去写材料，写了一天一夜。她托买菜的邻居绕过去看，邻居回来说，好像有个卖机器的，要八百。八百，她做不了主。

三月初九，下午三点。老蒯把泵又扛来了，家里实在没处搁。白秀英也来了，白糖泡了半尺，她打算自己先垫钱。阿茂也来了，他那天轮休，本来是到桥头找人下棋的。

三个人在西头撞上。老蒯说八百。白秀英说五百五。阿茂蹲下，伸手转了转叶轮，问：“皮带呢？”老蒯从蛇皮袋底翻出来。阿茂站起来，从口袋掏出那张四折的条子，摊平，一字一字念了一遍，说：“场地费免了，电从防汛那一路接。钱你们自己谈。”

最后七百。老蒯不肯租只肯卖，阿茂说：“我担保，明天卖不掉你原样拉回去。”白秀英写了一张欠条，按了手印。

泵拉走，接上电，抽了一夜。二十吨白糖救回来十九吨半。

五年前同一个仓库也漏过一回水。那次走的正规门路：打报告，等批复，比价，请外面的施工队，前后九天，花了三千二。

阿茂后来调去街道办，当了副主任。有一回开协调会，从两点开到五点四十，议题换过三次，还是没结论。他下楼抽烟，站在院子里看人往墙根堆杂物，看了很久。跟着他的年轻人问他在看什么。阿茂说：“那年救白糖，我们一共八个人，忙了三个钟头。后来我算过，真正起作用的不是我们——是三月初九那天下午，那台没处搁的泵、那个垫钱的女人、那张洗过三回的条子，还有我正好轮休。”

他弹了弹烟灰：“缺一样，就都不是这个结果。”

## 原来讲的是……

**概念：垃圾桶模型**

## 概念解释

垃圾桶模型（Garbage Can Model）由美国学者迈克尔·科恩、詹姆斯·马奇与约翰·奥尔森于 1972 年在《行政科学季刊》发表的文章中提出，用来描述一种被称为“有组织的无政府状态”的决策情境。它的基本判断是：组织中的决策并不是先有问题、再找方案、然后由决策者择优的线性过程；相反，问题、解决方案、参与者、选择机会是四股各自独立流动的溪流，它们各自有自己的生成规律与生命周期，只有在某一个时点上偶然交会，才会产生一次“决策”。

四股流的具体含义是：**问题**——组织内外大量未被处理的抱怨、故障、压力，它们随时在流动，有的消失了也没人解决；**解决方案**——各种已经成型却未必对应任何具体问题的办法，包括现成的技术、文本、预案、经验、“某某模式”，它们在组织内外游荡，寻找可以被附着的问题；**参与者**——人们的时间与注意力是流动的，谁在场、谁缺席、谁心不在焉，都带有偶然性；**选择机会**——会议、评审、批复、签约、突发事件处置这样的时点，是组织“必须做点什么”的时刻。

当四股流在某个选择机会上耦合，决策就发生了。因此决策结果高度依赖耦合的时机：同样的组织、同样的人、同样的问题，在不同的耦合下会给出完全不同的答案。这解释了两类常见现象：一是“议而不决”——会议开了很多次，问题在流、方案在流、人却换了，始终没撞上；二是“神来之笔”——某个搁置多年的方案，因为一次突发事件被迅速捡起并通过，看起来效率惊人，其实是方案早已备好，只等一个问题来认领。

需要特别澄清一个常见误解：垃圾桶模型并不主张“决策全靠运气”。它刻画的是**理性边界之外**的那部分真实机理。在目标明确、因果清晰、参与者稳定的情境里，理性决策模型仍然适用；但大量的公共部门决策恰恰处在目标模糊、技术手段有争议、人员频繁变动的状态中，此时假装用完全理性的框架去解释，反而会掩盖真相。模型的真正价值在于提醒管理者：既然耦合具有偶然性，那么可以人为经营的就不是“结果”，而是**耦合的概率**——让解决方案更容易被看见、让参与者更容易在场、让选择机会不被白白错过。

在公共管理与公务员考试语境中，这个模型有两重意义。其一是理论坐标：它是与完全理性模型、有限理性模型并列的重要常识考点，用来标识“决策理论谱系”中的一端。其二是实践视角：面对会议效率、议事协调机构、应急预案、政策试点等议题时，它提供了一个不那么乐观、但更贴近实际的批判性视角。

现实案例俯拾皆是。其一，某市早在数年前就编制过城市内涝应急预案，也采购了移动泵站，但一直躺在文件柜里；直到一场暴雨造成重大损失，预案被连夜启动，各方称赞“响应迅速”。方案的年龄远大于问题的年龄。其二，美国“9·11”委员会报告曾指出，联邦航空系统内部早在案发前多年就有关于加强驾驶舱门与安检的建议，这些建议在机构间反复流转，却始终没有找到一个必须拍板的时刻。其三，各级党政机关普遍存在的“领导小组”，本质上是把流动的参与者临时固定到一个选择机会上，从而提高耦合概率的组织技术——它能否奏效，往往取决于组长是否真的在场、会议是否真的必须出结论。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 三号仓库自来水管裂开、白糖被泡 | 问题流 | 问题独立生成、持续流动，不解决也会涨，但不会自己消失 |
| 老蒯那台为鱼塘配好却没用上的抽水泵 | 解决方案流 | 方案先于问题存在，闲置、游荡，等待被某个问题认领 |
| 白秀英、老蒯、阿茂、卖麻绳的老陈 | 参与者流 | 每个人的时间与注意力都是流动的，来不来带有偶然性 |
| 农历三、六、九的烂板桥开市 | 选择机会 | 必须做点什么的时间窗口，窗口开了不等于有人进 |
| 三月初三老蒯缺席、三月初六白秀英缺席 | 未耦合 | 流与流错开，问题仍在，方案仍在，没有任何事情发生 |
| 阿茂那天轮休、本要去下棋 | 偶然在场 | 关键参与者的出现本身就是随机变量，不是设计结果 |
| 那张洗过三回的临时处置条子 | 决策权限的临时配置 | 授权本身也是流动的，它决定耦合发生后能否立即生效 |
| 三月初九下午，四样东西同时出现在西头 | 耦合 | 决策在这一时点产生，而非在最优时点产生 |
| 五年前同样漏水，走正规流程九天、花三千二 | 反事实对照 | 同一组织在不同耦合下给出完全不同的结果与成本 |
| 阿茂多年后那句“缺一样，就都不是这个结果” | 模型的朴素表述 | 结果依赖耦合，而非依赖某个人的英明 |

## 公务员考试视角

行测常识判断中，这一模型常与“完全理性决策模型”“有限理性模型”“渐进决策模型”并列出现，考查点通常是提出者（科恩、马奇、奥尔森）、四股流的具体名称，以及它对应“有组织的无政府状态”这一前提条件，属于易混淆的对比性考点。申论中，它适合用于分析“反复开会却推不动”“预案沉睡”“部门协调难”一类材料，写对策时不应停留在“加强重视”，而应落到提高耦合概率的具体机制上，比如固化议事时点、建立方案库、明确临机处置授权。结构化面试谈到会议效率、决策机制时，用它可以显示出批判性：既承认偶然性的存在，又指出偶然性可以被经营。切忌在答题中把它简化为“决策靠运气”，那是最常见的失分点。

## 思考题

1. 如果三月初九那天阿茂没有轮休、照常上班，故事会走向哪个结局？这个假设说明了模型中哪一股流的性质？
2. 五年前那次花了三千二、九天时间，参与的人更多、程序更正规，为什么结果反而更差？用四股流分别说说差别在哪里。
3. 阿茂手里那张条子，如果三月初六就摊开，能不能救下那二十吨白糖？请回到故事里，找出至少两个阻止它生效的具体障碍。
