# 筷子立不住

## 寓言故事
光绪二十三年冬，江北流民南下，江阳县城外聚了三千口。

知县周敬山刚接到吏部考功文书，三年一考，最要紧是“赈务无误”。他叫来主簿沈砚，口述告示：城南设粥厂三处，自冬至起每日赈五百口，粥须厚，“插筷不倒”。

沈砚落笔。写到一半，师爷范先生按住纸：“‘三处’太死，上头问起不好答，写‘酌设数处’。‘五百口’也死，写‘以济饥民为度’。米呢？库里没有。”定稿是：城南各坊酌设粥厂，米粮由各坊就地筹措，官署贴补三成，务使粥厚，可插筷不倒。

沈砚抄了十二份发下去。

城南坊里正老吴算了半夜：五百口吃四十天，要米六十石；官署贴三成，剩下四十二石自己想办法。他去求米行曹掌柜。曹掌柜仓里有二百石去年受过潮的陈米，原要倒进河里，如今半价卖他，还拍肩：“掺些糠，熬得住火，饿汉喝稀的才养人。”

粥厂没设在街口，设在城隍庙后的空地。街口几家绸缎庄、茶楼联名递了帖子，说流民聚在门前，生意没法做。开厂时辰也从卯时挪到辰时，巳时收锅——两个时辰，够人喝完就走，街上清爽。

掌勺刘三原是庙里火工。头一日米下得实，锅底焦了一层。第二日他学乖了：米减三成，水加两担，柴省一半。他管这叫“熬时辰”，熬得久，米粒开花，汤也白，看着同厚粥一样。至于插筷不倒，刘三留了心眼：灶边单放一口小铁锅，米下得极厚，官差来了便从那锅里盛一碗。

腊月初八，周知县下乡劝农，顺路来看粥厂。前一夜差役先到，老吴借了二十条长凳，几十个流民被叫去河边洗脸，换上庙里存的白布短褂，捧碗在长凳前排队。门上挂红绸，两侧贴“惠及穷黎”。周知县尝了半碗灶边小锅的粥，筷子插进去，直直立着。他点头，对沈砚说：“记下来，插筷不倒。”

沈砚没说话。

后来他又自己去过两次，不打招呼。辰时三刻，队伍散得差不多。他排末位，接过一碗。粥是温的，能照见天光。筷子插下去，倒向一边，浮起几粒碎米。

他问刘三：“为什么不煮厚些？”

刘三正刷锅，头也没抬：“厚了，一顿顶两顿，人就不来了。人不来，里正说上头要问。再说柴也不够。”

他去问老吴。老吴把账本推过来，一页页是米、糠、柴、工钱，最后一行结余：零。老吴说：“沈主簿，我不是没照办。可你发下来的告示上，哪一句写过这粥一定插得住筷子？”

沈砚回衙，翻出那天的底稿。十二份抄本，每一份上都端端正正写着他自己的八个字——“因地制宜，量力而行”。

那一夜他没睡。

**概念：政策执行偏差**

## 概念解释
政策执行偏差指公共政策在从决策层向目标群体传递的过程中，执行主体对政策目标、手段与对象进行再解释、再加工，使实际结果与既定目标之间出现系统性、方向性的落差。它的成立通常需要三个条件：政策文本留有裁量空间，目标笼统、标准定性、时限有弹性；执行链条上存在多层级委托代理，每一级都有自己的成本与考核；监督所需的信息主要由被监督者自己生产。三者同时具备时，偏差就不是偶发失误，而是可以被预见的稳定产出。

常见形态有四种。象征式执行是动作做足、结果不发生，如挂红绸、摆长凳、灶边单留一口厚粥锅；选择性执行是在政策的多项目标中挑容易的、考核权重高的做，把难的、得罪人的搁置，如粥厂挪到庙后、只开两个时辰；替代式执行是用另一件事替换政策要求的事，如陈米加糠替换新米厚粥；附加式执行是执行中自行加码，把“完成任务”变成“超额完成”，成本转嫁给基层和群众。

学术上，1973 年普雷斯曼与维尔达夫斯基出版《执行》，研究美国联邦就业培训与公共工程拨款在奥克兰的落地，发现钱拨下去了，工程几乎没建起来。这本书把“执行”变成独立研究对象，并确立一个判断：政策失败常常不在决策，而在决策之后。1980 年代形成两派：自上而下派关注中央如何以清晰法规、充足资源与严格问责锁定执行；自下而上派以利普斯基的“街头官僚”为代表，指出一线人员握有大量日常裁量权，政策实际上是他们在具体情境中“做”出来的。马特兰德提出模糊—冲突模型：目标模糊而冲突不高的政策，执行高度依赖基层情境，结果最不可控。中国研究中，欧博文与李连江提出“选择性政策执行”，描述乡村干部对上级多项政策区别对待；周雪光以“共谋”“变通”解释多层级治理中上下级联合应对更上一级检查的机制。名称不同，问的是同一个问题：为什么好政策到了下面会变样。

把偏差归因于“素质不高”“作风不实”，是最省事也最无效的解释。执行者面对的是三样硬约束：任务与资源不匹配，钱、人、时间都不够；考核指标与政策目标不重合，考核人数就没人管质量；被追责的风险不对称，做多了出错要担责，不做最多挨批。在这些约束下，被观察到的“变形”往往是执行者的理性反应。

两个现实案例。一是“厕所革命”中的改厕：华北某县为完成年度户数，统一采购廉价塑料化粪池，不接入污水管网，验收以拍照留档、签字确认为准，数字完成了，设备第二年冻裂弃用。这是象征式执行，起点则是“户数作为唯一考核指标”的设计。二是环保督察中的“一刀切”：某地在督察进驻前对辖区内所有小加工厂一律断电停产，包括早已达标的企业，既是为降低风险的附加式加码，也是把“整改”替换成“全部关停”的替代式执行。两案的共同点是，政策目标没有被否定，被改写的只是达成目标的方式，以及成本由谁承担。

## 隐喻对应表
| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 周知县口述的“三处、五百口、插筷不倒” | 政策目标与标准 | 目标看似具体，但关键条件依赖下游解释 |
| 范师爷改成“酌设数处”“以济饥民为度” | 政策文本模糊化 | 为应对上级追问而预留裁量空间，执行标准随之软化 |
| 官署只贴补三成，其余各坊就地筹措 | 执行资源不足与责任下移 | 任务下达了，成本却由基层自行消化 |
| 曹掌柜半价卖陈米，建议掺糠 | 替代式执行 | 用可得资源替换政策要求的资源，形式上仍在“办粥厂” |
| 粥厂挪到城隍庙后，只开两个时辰 | 选择性执行 | 避开街面利益冲突，优先完成“不出事”的目标 |
| 刘三减米加水，灶边单留小锅厚粥 | 象征式执行与信息不对称 | 检查时看得到的是小锅，群众喝到的是大锅 |
| 腊八前洗脸、换褂、借长凳、挂红绸 | 监督失灵与迎检表演 | 监督所需信息由被监督者布置，检查看到的是布景 |
| 老吴账本最后一行“结余：零” | 激励结构 | 基层在资源紧约束下按可考核项行动，而非按文本原意 |
| 沈砚私访时筷子倒向一边 | 自下而上的执行视角 | 只有进入末端场景，才能看到政策实际被加工成什么 |
| 底稿上“因地制宜，量力而行”八个字 | 裁量授权与责任模糊 | 授权本身合理，但缺少边界与问责，便成为偏差的入口 |

## 公务员考试视角
行测常识可能考政策执行的代表性研究、街头官僚、选择性执行等概念与人物对应。申论中，“政策落地的最后一公里”、基层治理、形式主义是高频主题，给定材料常呈现“文件好、落地难”的情形，作答时应从政策设计、资源匹配、考核激励、监督信息四条线分析，避免只批评基层作风。结构化面试中，若问“某项惠民政策群众反映没获得感，你怎么看”，可先区分决策问题与执行问题，再谈如何让考核指标与政策目标对齐、让监督信息来自群众而非台账。核心是用“激励结构”解释行为，而非用“素质”解释一切。

## 思考题
1. 告示底稿上“因地制宜，量力而行”八个字，在故事中分别被老吴、刘三和沈砚怎样理解？这八个字是授权，还是漏洞？
2. 如果周知县把“插筷不倒”改成“每碗米不少于三两、当场由流民代表签字”，腊八那天的场景会怎样变化？哪些人的行为会先改变？
3. 沈砚两次私访都选在辰时三刻之后，这个时间点让他看到了什么？如果他只在腊八随知县到场，他会写下怎样的评语？
