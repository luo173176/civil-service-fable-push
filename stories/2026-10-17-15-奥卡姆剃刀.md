# 第三个排水嘴

## 寓言故事

清河县连下了四十天雨。西城墙鼓起来一段，墙皮一块块往下掉，夜里能听见砖缝里咕咕的水声。

县丞姓吴，急得嘴上起泡。他请三拨人来看。第一拨说，前年修墙石灰掺沙，墙基虚了，得重砌；第二拨说，墙外土地庙压住了水脉，得迁庙；第三拨说，城西地势低，得沿墙根开一条暗渠，把水引到护城河。三份呈文摞在一起，报上去要银八百两。

动工前一日，管工房的老书吏说，不如叫周泥瓦来看看。周泥瓦六十多岁，砌过东门瓮城，如今在城外烧砖。吴县丞嫌他土，但人已经请来了。

周泥瓦不说话。他围着那段墙走了两圈，蹲下抓一把墙根的土，在手里捻；又站起来看墙头。雨刚停，墙头上还挂着水珠。他问：“这墙顶，留了排水嘴？”

工房的人说：“留了，五个，隔三丈一个。”

“带我看第三个。”

搬梯子上去。第三个排水嘴被一团烂叶堵得严严实实，叶子里还夹着一只死麻雀。水从墙顶漫出来，顺着砖缝往墙肚子里灌。周泥瓦用铁条一捅，水哗地泻下来，淌了半炷香的工夫。墙肚子上鼓的那一块，眼见着瘪下去。

吴县丞站在梯子底下，脸上红一阵白一阵，说：“这……这只是碰巧。墙基还是要砌的，庙还是要迁的，暗渠——”

周泥瓦从梯子上下来，拍了拍手上的泥：“大人，水是从上头灌进来的。您要砌墙基，我不拦；要迁庙，我也不拦。只是先把这五个嘴子都捅一遍，再看不迟。”

那天下午，五个人上去，把五个排水嘴全掏了。掏出来的东西有烂叶、有鸟窝、有半块碎瓦。西城墙再没鼓过。

周泥瓦回到砖窑，徒弟小栓问他：“师父，您咋知道是那个嘴子堵了？”

周泥瓦说：“我不知道。我只知道，墙没塌，是水没处走。水没处走，先看水从哪儿来。看水从哪儿来，比猜山挪了地方容易。”

小栓没全听懂，但记住了。

三年后，小栓进了县衙，在工房抄写。那年一户人家的男人死在口外，婆媳俩要分三亩水田，按例要跑五个衙门、开七张证明。吴县丞已经升了主簿，主张设一个“清田局”，添四个书吏，专办此类事。公文递上去，小栓在工房值夜，把那七张证明的底子一张张摊在桌上。

他看了半宿，发现其中三张要的其实是同一件事：这家有几口人。还有两张，是同一块田的四至，只是衙门不同，问法不同。

第二天，他没说设局不对，只说：“大人，这七张纸里，有三张是一件事。能不能先并成一张？”

吴县丞皱眉，让他试。并了，那户人家少跑三个衙门，清田局也没设。

小栓后来跟人说，这是他师父教的：先数一数有几件事，再数一数要添几个人。

那年冬天，吴县丞调任邻县，临走前把小栓叫到廊下：“你师父那年要是没来，我这八百两银子就花出去了。”他从袖里摸出一张旧纸，是当年三份呈文的抄底，背面有周泥瓦用炭条画的一排小圈，五个，第三个涂黑了。

小栓后来才知道，这种先找最省事那个解释的法子，有个名字。

## 原来讲的是……

**概念：奥卡姆剃刀**

周泥瓦不知道这个词。他只知道，在几种说法都还站得住的时候，先试那个假设少、成本低的。这条偏好，十四世纪一位修士替它起了名字。

## 概念解释

奥卡姆剃刀通常被概括为“如无必要，勿增实体”。它说的是：当两个解释在解释力上相近、彼此打平时，优先选择假设更少、引入实体更少的那个。“打平”是核心限定——简单解释若漏掉证据，剃刀就不能用。它不是“简单即真”，而是一种方法论上的默认偏好，决定先试哪一个，而不是宣布哪一个为真。

提出者一般归于十四世纪英国方济各会修士、逻辑学家奥卡姆的威廉（约1287—1347）。他在神学与逻辑论辩中反复批评论敌不必要地增设“实体”，后世把这种倾向概括为“不必要地增加实体”的规则。那句著名的拉丁文并非他著作中的原句，而是后人的提炼。需要强调，奥卡姆剃刀不是逻辑真理，也不是判定真假的证据法则。它不保证简单解释正确，只保证在证据尚未拉开差距时，我们先不付出额外假设的成本。

适用有三个条件。第一，被比较的解释必须具备相同或相近的解释力，能覆盖同样的现象。第二，不能为了求简而砍掉证据，把不符合简单模型的事实当作噪声。第三，剃刀给出的是“先试哪个”的次序，不是“只许哪个”的禁令。证据一旦偏向复杂解释，剃刀就该收起来。

在公共管理与行政法中，这一思路几乎贯穿近年的审批改革。“减证便民”“多证合一”“证照分离”“一网通办”，本质上都在追问：这件事真的需要这么多证明、这么多窗口、这么多环节吗？能由一张表说清的，不必拆成五张；能由部门间共享的数据，不必让群众重复提交。但“减”有边界：食品药品审评、生态环境监管、安全生产检查中的必要程序，是不能为求简而砍掉的“证据”。

现实案例一：浙江“最多跑一次”改革。做法是梳理“一件事”的全流程，把重复材料、重复证明合并，让数据在部门之间跑。其判断前提正是：群众办这件事，本来只涉及几件事实，多出来的材料是“增出来的实体”。改革不是把所有材料一删了之，而是先确认哪些事实已由现有证照和数据覆盖。

现实案例二：国务院清理证明事项。此前“证明我妈是我妈”一类要求，让群众用多份证明去印证同一件事实。清理的思路是先确认哪些事实已由现有证照、户籍数据可以说明，再取消重复证明。它不是取消一切证明，而是取消解释力已被覆盖的多余证明。

在公务员考试中，这一原则是逻辑判断题的“元原则”之一：加强、削弱、解释型题目里，需要额外引入新假设才能成立的选项，通常不是最优；能直接解释题干现象、不节外生枝的选项更稳。申论写流程优化、基层减负、营商环境，可以用“能合则合、能减则减、能并则并”的框架，但要补一句“必要监管不减”。面试的应急应变题，先排查最直接、成本最低的原因，再谈成立专班、新建机制，往往更贴近实际。

需要防止两个误解。其一，把剃刀当成真理判据，认为简单的解释一定对。其二，把剃刀当成偷懒的借口，用“简单”掩盖本该做的调查。周泥瓦蹲在墙根那半日，不是省事，是把最省事的那条线索先查实了。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 西城墙鼓胀 | 待解释的现象 | 同一现象可被多种假设解释，需要确定先试哪一个 |
| 三拨人的三份呈文 | 增设实体的复杂假设 | 重砌墙基、迁庙、开暗渠各自成立，但都需要额外投入与额外前提 |
| 八百两银子的预算 | 假设成本 | 每增加一个实体，就增加一份可核查的成本与风险 |
| 第三个排水嘴里的烂叶与死麻雀 | 被忽略的直接证据 | 简单解释之所以优先，是因为它指向可查、可验的具体事实 |
| 周泥瓦说“我不知道” | 剃刀不是真理判据 | 他并未断言墙基无问题，只是先查成本最低、最可验证的一环 |
| 捅开五个排水嘴后墙瘪下去 | 解释力打平后的取舍 | 证据一旦支持简单解释，复杂方案暂时失去必要 |
| “先捅一遍，再看不迟” | 次序而非禁令 | 剃刀给出排查顺序，不排除后续仍要砌基、迁庙 |
| 七张证明里三张是同一件事 | 重复设置的多余实体 | 行政流程中的“增证”往往不是新事实，而是同一事实的重复问法 |
| 不设清田局、不添四个书吏 | 能合则合的组织设计 | 合并环节即可解决，无需新增机构与编制 |
| 小栓“先数几件事，再数添几个人” | 方法论偏好的日常表达 | 先确认事实个数，再决定制度成本，是剃刀的行政版本 |

## 公务员考试视角

行测常识可能以“方法论原则”形式出现，例如问哪种做法体现“如无必要，勿增实体”，或在逻辑判断中要求选出“不依赖额外假设”的选项。申论中，流程优化、基层减负、优化营商环境是高频主题，可用“合并同类环节、取消重复证明、必要监管不减”作为分论点骨架，避免写成“越少越好”的极端表述。结构化面试的应急应变与组织协调题，先排查直接原因、再用低成本措施，比一上来就“成立专班、建立机制”更得分；但要在结尾补一句“若排查后确属结构性问题，再启动相应程序”，体现剃刀的适用前提。

## 思考题

1. 吴县丞的三拨人说的都“有道理”，故事里凭什么判断先查排水嘴而不是先砌墙基？如果把“解释力相同”当作前提，三份呈文与捅排水嘴真的打平吗？
2. 小栓合并三张证明时冒了什么风险？如果那三张里有一张其实问的是另一件事，合并会造成什么后果？
3. 周泥瓦说“我不知道”，这句话在故事里起了什么作用？它与“简单的一定是对的”区别在哪里？
