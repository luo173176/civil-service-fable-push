# 议事堂的旧匾

## 寓言故事

柳溪镇的悦来客栈换过三回招牌。第一块是“悦来客栈”，第二块是“柳溪商务酒店”，第三块是去年挂上去的“悦来效率示范店”，金字黑底，据说是镇评比的奖。

老板娘姓周，四十出头，算账快，眼睛更快。她给伙计定了三条规矩：客人进门三十秒内递热毛巾；点菜到上菜不超过一刻钟；一天翻台过四轮。伙计们跑得脚不沾地，账本一年比一年厚。周老板娘逢人便说：我这店，靠的是一套硬指标。

可镇上的人渐渐不来了。不是嫌贵，是嫌赶。老主顾刘木匠说，我去吃碗面，热毛巾塞到手里还没擦完嘴，面就端上来了，筷子一放，伙计的眼睛就瞟着桌子等我走。像什么？像被清点的一件货。

周老板娘不服气，添了第四块牌子：意见簿。挂在门边，一个月没人写。她翻开看，只有一页，是刘木匠的孙子代笔的，写着：我爷说，他想在店里坐一会儿。

那天来了两个人。一个是镇上连锁店派来的经理，西装笔挺，进门第一句是“您的翻台率全镇第一，我们想收购您的地段”。另一个是镇上的老文书，姓陈，抱来一块蒙灰的木匾，说是清库房翻出来的旧物，民国年间的东西，上面刻着三个字：议事堂。

周老板娘看那匾，木头裂了，字也浅。“这什么？”

老陈说，早年间这店还不是客栈，是镇上人凑钱盖的，议事、说理、办红白事都在里头。谁家水渠挖偏了，谁家孩子读书缺钱，都在这屋里坐着说。说完了，散场，各回各家。后来生意要紧，房子一层层改，屋里的桌子换成了灶台。

连锁店经理第二次来，把合同摊在案上：只要按他们的标准做，明年一个店变三个店。

那天晚上，周老板娘在账房坐到半夜。她翻账本，一页页都是数字，翻到最后停住了。她忽然想起一件事：这三年，她没在店里跟谁好好说过一句话。

第二天，她把“悦来效率示范店”的金字招牌摘下来，靠在墙角。伙计以为要歇业，她却让人把二楼堆杂物的屋子清出来，把那块裂了的旧匾擦干净，钉在门楣上。

她定了新规矩，只有一条：每天午后，店里关半个时辰的灶，谁愿意来坐就进来坐。

头几天没人来。第四天，刘木匠拖了张凳子进来。第五天，卖豆腐的、教书的、看水闸的都来了。说的也不全是大事：有人抱怨新修的排水沟，雨天积水没过脚踝；有人说孩子学籍没着落；有人只是坐着。

周老板娘不催，也不记账。她泡一壶茶，听完就记在本子上。本子上不再是数字，谁的话都有一行。有人问她图什么，她说：我原来以为店里最好的东西是那块金字招牌。

后来她真听见了几句有用的：卖豆腐的说镇上要修路，教书的说班上有三个孩子家里没人接送，看水闸的说上游闸门一开，柳溪的水就浑。半年后，镇上要议排水的事，来了十几个人自报家门，说是“在悦来议事堂坐过的”。

连锁店经理再来，看见门楣上那块旧匾，愣了一下，说：这不合规矩。周老板娘说：我这店原来最大的毛病，就是太合规矩了。

老陈后来去喝茶，问她：不怕客人被这一坐坐跑了？她指着那本记满话的本子说：流水是少了一半，可如今有人肯跟我商量事。以前客人是来消费的，擦完嘴就走；如今有人来，是为了把这镇上的事情说清楚。

## 原来讲的是……

**概念：新公共服务**

## 概念解释

新公共服务（New Public Service）由美国公共行政学者珍妮特·登哈特与罗伯特·登哈特夫妇在20世纪末系统提出，代表作是《新公共服务：服务，而不是掌舵》。它是对新公共管理的批判性矫正，也是公共行政理论演进中的重要一环。

新公共管理的核心假设是：政府应当像企业一样运营，公民被视为“顾客”，公共利益被理解为个人偏好的加总。由此衍生出一整套以效率、绩效指标、市场化和外包为核心的治理模式。这套模式在改善行政效率、约束预算扩张方面确有成效，但也带来明显后果：公共服务的提供者开始把公民看作消费者，把行政活动压缩为一组可量化的产出，而公共领域中那些难以度量却至关重要的价值——公平、参与、责任与信任——被边缘化。

新公共服务的提出，正是要扭转这一价值坐标。其核心主张可概括为四点。

第一，“服务而非掌舵”。登哈特夫妇认为，政府的主要职责不是亲自为社会定方向并驱赶社会向前，而是帮助公民表达并实现他们的共同利益。公共利益不是个人偏好的简单相加，而是通过公开对话、协商与审议形成的产物。行政人员在其中扮演召集人、协调者和推动者，而不是发号施令的舵手。

第二，重视公民权与公民参与胜过企业家精神。公民不是被动的服务接受者，而是拥有权利、承担义务、具有参与能力的权利主体。他们参与公共事务的权利不能被消费关系所替代。行政人员的责任之一，就是培育和维护这种参与能力，让社区的自我治理得以展开。

第三，责任的多重复合。新公共服务反对把行政责任简化为若干绩效指标。行政人员的责任同时来自宪法与法律、专业伦理、政治共同体的价值期待、公民的直接诉求与社会规范。这些来源有时并不一致，行政人员必须判断、权衡并公开说明理由，而不是用单一指标回避决策的复杂性。

第四，重视人，而不只是生产率。公共组织若只以产出衡量一切，最终会耗尽成员的判断力与服务意愿；尊重人、信任人、通过合作与共享领导来运作，才可能持续产出好的公共服务。

需要特别澄清一个常见误解：新公共服务并不是主张退回传统官僚制，也不是否定效率。它所做的是一次价值序列的调整——效率仍然重要，但不再是唯一的评价尺度；民主、公平、责任与参与被置于优先位置。用一句话概括：衡量公共服务的价值尺度，从“效率优先”挪到了“民主优先”。

在现实层面，新公共服务的理念有诸多对应实践。其一，浙江温岭的“民主恳谈会”：地方政府就财政预算等公共事项组织公民参与协商，参与者在公开平台上讨论、质询并影响预算安排，体现了公共利益经由对话协商形成的思路。其二，北京“接诉即办”机制：市民通过热线反映问题，政府在解决问题的同时对诉求数据分类研判，从“办好一件事”走向“解决一类事”，其中对民意回应的强调，与把公民视为权利主体而非顾客的取向相通。其三，基层社区议事厅、村民议事会等制度安排，把协商嵌入日常治理，是参与能力培育的具体形态。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| “悦来效率示范店”金字招牌 | 新公共管理的绩效导向 | 以量化指标作为唯一成功标准，代表效率优先的评价体系 |
| 三条硬规矩：三十秒递毛巾、一刻钟上菜、一天四轮翻台 | 以可量化产出为核心的行政模式 | 指标明确、便于考核，但把服务对象当作待处理的流程节点 |
| 连锁店经理携合同收购 | 市场化、企业化治理的吸引力 | 规模扩张与标准化运营的诱人逻辑，代表效率话语的现实压力 |
| 刘木匠说“他想在店里坐一会儿” | 公民身份而非顾客身份 | 顾客只要求高效获得商品，公民则要求被当作有尊严、有能力的主体对待 |
| 裂了缝的“议事堂”旧匾 | 民主价值与协商传统 | 旧匾本就在，只是被遮住了；隐喻民主价值是公共治理的内在传统，不是外来的添加物 |
| 摘下金字招牌、重挂旧匾 | 价值坐标的更换 | 不是退回旧制度，而是把价值尺度从效率移到民主 |
| 每天关半个时辰灶、谁愿来就来 | 政府角色从掌舵转为服务 | 职责是创造协商平台、维护参与条件，而非亲自指方向并驱赶社会 |
| 新规矩只有一条 | 责任的多重复合而非单一指标 | 放弃用指标堆砌责任，转向对法律、价值、民意等复合来源的判断与回应 |
| 记满话语而非数字的本子 | 公共利益经由对话生成 | 账本只记录交易额，公共利益无法由个人偏好加总得到，只能在对话中形成 |
| 半年后十几人自报“议事堂坐过的”参与议水 | 公民参与能力的培育与溢出 | 参与不是一次性消费，它会积累为社区自我治理的能力 |
| “这店原来最大的毛病，就是太合规矩了” | 对唯指标论的反思 | 一味追求单一标准，反而偏离了公共服务的目的本身 |

## 公务员考试视角

在行测常识判断中，这一概念可能以“公共行政理论演变”的形式出现，要求考生辨识新公共管理与新公共服务的主张差异，典型设问是“下列哪项属于新公共服务的核心主张”。在申论中，它是论证全过程人民民主、基层协商治理、服务型政府的学理支撑，可用以阐释“从管理到治理”“从效率到回应”的转变，避免空泛表态。在结构化面试中，涉及群众议事、意见征集、指标考核类题目时，可用它表明立场：不以数据替代民意，不以流程替代沟通，把群众当作权利主体而非服务对象；同时须注意分寸，强调这是价值尺度的调整，而非否定效率与绩效管理，以体现辩证思维。

## 思考题

1. 故事里周老板娘新定的规矩只有一条“每天关半个时辰的灶”，旧规矩却有三条。这个“减”究竟是放松了管理，还是更换了管理的目标？如果把那半个时辰的谈话也算作成本，她到底亏了还是赚了？
2. 那块“议事堂”旧匾本来就堆在库房里，并非外来的新东西。作者为什么这样安排，而不是让周老板娘去城里请人新刻一块？
3. 连锁店经理说“这不合规矩”时，他所说的“规矩”具体指什么？如果让你替周老板娘回答，你会怎样在不否定效率的前提下说明自己的选择？
