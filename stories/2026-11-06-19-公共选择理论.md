# 堤往哪边挪

## 寓言故事

石桥镇的堤，年年修，年年挪。

陈九头一年当堤董。这差事没有俸禄，只有一身泥。他接手时，账上剩四十七两银子。

头一件是定堤线。镇上有老规矩：一户一票，票多者定。河湾南边是李家三十亩水田，北边是赵家二十亩沙地。李家五房，各立门户，五张票；赵家只一张。于是堤线往南压了三尺，李家那片低田护得严实，赵家的沙地被撇在堤外。赵家老汉在议事堂门口蹲了一夜，天亮时说：“我认。”他把沙地改种了柳条——柳条淹得起。

第二件是买土。陈九跑了三家窑，价钱都问了。到了签字那天，账房把单子推过来，承揽人写的是窑主的外甥。陈九问：“价低的那家呢？”账房说：“那家窑在李家地界，运费高。”陈九自己算了算，运费加进去，其实还低二两一钱。他把笔搁下了。

搁了三天。镇上有人来劝：“陈师傅，你一个人挡不住的。往年堤董都是这么签的。”第四天，他签了。

第三件是摊钱。按田亩摊，一亩一钱。李家三十亩出水田，共三钱；赵家二十亩沙地出二钱，堤却没护着。这回赵家老汉没认，在议事堂上说：“我出钱，护的是别人的田。”众人低头喝茶，没人接话。钱他还是出了——不出钱的人，来年挑土时没人帮工。

堤修成那年水不大，没塌。第二年水大，堤在赵家沙地那侧决了口。水灌进来，先淹了柳条，再淹了李家五房里的两房。

事后查验，决口那段正是当年为省银子换了土的一段。

陈九在祠堂里坐了一夜。他想起三件事：票是怎么投的，土是怎么买的，钱是怎么摊的。三件事他一件也做不了主，可他桩桩都签了字。

转过年来，镇上来了个教书的年轻人，姓沈，在议事堂的墙上贴了一张纸，写了四条：一、修堤前先公示各户受益田亩，贴十日，任人来看；二、堤线须得七成票，不是过半；三、承揽须三家比价，价、运费、保固年限一并贴出；四、堤董、账房三年一换，换时交账，账本子任人抄。

有人问：“这四条顶什么用？人还是那些人。”

沈先生说：“人还是那些人。先定下怎么走，再抬脚。”

那年定堤线，往北挪了两尺半。赵家老汉破天荒投了赞成票。陈九问他为啥改主意。老汉说：“我不知道。反正这一回，我算得清。”

第三年清明，沈先生在纸上写了一行小字，塞进祠堂的砖缝。陈九不识字，托人念。念的人先说：“这不是说咱们镇。这是说所有要投票、要花钱、要用人办事的地方。”顿了顿，又念道：“有人研究管市场的人，用管市场的法子去研究管人的人——布坎南，塔洛克。一九八六年那笔诺贝尔奖，给了他们这个。”

## 原来讲的是……
**概念：公共选择理论**

## 概念解释

公共选择理论（Public Choice Theory）由詹姆斯·布坎南与戈登·塔洛克在二十世纪五六十年代创立，布坎南因此获1986年诺贝尔经济学奖。它的核心主张可以用一句话概括：把经济学分析市场的方法，原封不动地搬到政治领域来用。

**关键条件有三个。**

第一是方法论个人主义。解释集体行为时，不能把“政府”“议会”“村委会”当成一个会思考的整体，必须还原到具体的个人：投票的人、签字的人、拨款的人、盖章的人。政策是这些人做出选择的结果，不是组织自己“决定”的。

第二是“经济人”假设的移植。市场里人追求自身利益，这一点大家容易接受；但政治场上的人同样如此。选民会算自己那票值不值当去投，政治家会算选票与连任，官僚会算本部门预算与编制。这不是说政治人都腐败，而是说不能用“道德更高尚”来作为制度设计的前提。

第三，因此需要立宪层面的规则设计。布坎南区分“规则之下的博弈”与“关于规则的博弈”：日常政策是前者，宪法与章程是后者。他的主张是先就程序、权限、公开、表决门槛达成共识，再在这个框架里逐项博弈。规则本身要比具体政策更稳定、更公平。

**一个常见误解要先排除**：公共选择理论不是主张取消政府、把一切都交给市场。它说的是，既然市场会失灵，那么用来矫正市场的政府同样可能失灵，甚至引入新的扭曲。市场失灵不是政府干预的充分条件，还要证明“政府做得更好”；而这一点需要制度来保证，不能靠宣誓。

与它相关的几个子命题常出现在文献里：投票悖论与议程操纵（谁定投票顺序，谁就部分决定了结果）；集中收益、分散成本（少数人拿到明确好处，多数人各损失一点点，谁都没有动力去反对）；官僚预算最大化（部门倾向于把预算做大，而非把事做省）；财政幻觉（纳税人感觉不到自己付了多少钱）。这些不是道德指控，是激励结构的必然产物，只能靠制度来对冲。

**现实案例很多。**

其一，政府采购中的“参数围标”。某地采购设备，技术参数写得极细，恰好只有一两家产品能满足；参数由使用部门自己起草，理由总是“专业性”。事后审计发现，参数起草人多次接受过那家供应商的“技术交流”。公共选择理论对此看得并不意外：起草规则的人就是受益的人之一，除非把“起草”和“审定”拆开、把参数公开征询、把质疑渠道做实，否则同类事情会反复出现。

其二，农业与部分行业的保护性政策。某项关税让全国每个消费者一年多花几十块钱，谁也不会为此上访；但它让少数几家企业多出几千万利润，它们有充分动力去游说、去提供论证材料。收益集中、成本分散，议会的表决结果不难预测——这不是议员“被收买”就能解释的，是激励结构使然。

其三，也是更贴近日常的：村一级的小型工程。凡是“谁出工、谁受益、谁签字”三者模糊的地方，工程价必然偏高、质量必然偏低；反过来，把受益田亩公示、把比价贴出来、把管账的人定期更换，往往不动一分钱预算，效果就大不相同。这是公共选择理论在基层最朴素的应用：改的不是人，是规则。

在公共管理与公共政策语境中，这套理论的价值在于提供了一把“反向检验”的尺子。评估一项政策时，除了问“应不应该做”，还要问“执行它的人从这项政策里得到什么、失去了什么”“谁会为它付出看不见的成本、谁能拿到看得见的好处”。这不是犬儒，而是把制度设计建立在可验证的人性假设上，而不是建立在期望之上。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 一户一票、票多定堤线 | 多数票规则与议程结果 | 表决规则本身直接决定资源分配，李家五房“人多票多”，堤线便向有利于他们的方向偏移 |
| 李家五房分立门户各得一票 | 方法论个人主义 | 不是“李家”在投票，是五户各自盘算；集体偏好由个人偏好加总而成，而加总方式可被利用 |
| 陈九明知价低二两仍签了字 | 官员的个人理性与制度约束 | 他并非坏人，但“一个人挡不住”的预期成本让守信变得不划算；约束制度缺位时，好人也办坏事 |
| 账房把工程给了窑主外甥 | 寻租与“集中收益、分散成本” | 多付的银子摊到全镇每亩一钱上，几乎无人追究；拿到好处的是具体的人 |
| 赵家出钱护别人的田 | 成本与收益的不对称 | 承担成本者与获得收益者分离，是政策偏离公共利益最典型的形态 |
| 决口处正是换土那段 | 政府失灵 | 干预本意是防洪，结果因执行结构问题反而放大了风险，政府并非天然校正者 |
| 沈先生贴出的四条 | 立宪层面的规则设计 | 公开、门槛、比价、轮换，全是“关于规则的规则”，先于具体工程而存在 |
| 堤线北移两尺半、老汉投赞成票 | 规则改变激励，进而改变结果 | 人未更换，行为已变——这是理论最关键的预测 |

## 公务员考试视角

**行测常识**最可能的考法是直接对应：1986年诺贝尔经济学奖得主布坎南、《同意的计算》与塔洛克、公共选择理论属于“经济学方法研究政治现象”。也可能放在“市场失灵与政府失灵”的并列选项里，要求判断“政府干预一定能校正市场失灵”为错误表述。

**申论**里，这套框架适合用在“政策执行走样”“基层微腐败”“财政资金低效”“部门立法”这类材料上。写法上不要贴标签，而是用“收益集中在谁、成本分散给谁、执行者有什么激励”三句话拆解材料，再提出公开、比价、轮换、门槛、第三方评估等程序性对策——对策必须落在规则上，而不是“加强教育”“提高觉悟”。

**结构化面试**中，遇到“某惠民工程群众不满意”“某地反复修路”这类题，可以先讲机制：谁定的方案、谁签的字、谁承担成本、信息是否公开。这样答题会比“责任心不强”深一层，也更像政策思维。

## 思考题

1. 陈九三次都签了字，三次都不是为自己。如果要他在第一次买土时就拒绝，需要事先存在什么条件？故事里哪一条“四条规矩”恰好补上了这个条件？
2. 赵家老汉第一次“认了”、第二次反对、第三次赞成，他的处境和判断分别因为什么发生了变化？把堤线从“过半”改成“七成”，改变的是票数还是别的什么？
3. 沈先生说“这不是说咱们镇”。如果把这四条搬到一个县、一个部门，哪一条最难落地？卡在哪一步？
