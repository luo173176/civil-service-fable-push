# 五张化验单

## 寓言故事

老周咳了三个月。

县医院的大夫听了听后背，说，得查。笔一挥，五张单子推过来：验血、拍片、B超、查痰、心电图。

老周捏着五张纸站在门诊大厅。大厅像一口锅，人挤人，头顶的电扇把汗味搅匀。

第一张，验血。窗口说，先交费。他下到一楼交费，再上二楼。抽完血，护士说，下午四点取。

第二张，拍片，在三号楼。穿过停车场，三号楼是栋旧楼，门口排着长队。轮到他，登记的人说，先交费。他又折回一号楼。

一上午，他摸清了规矩：每一张单子，都要先交一次费，再排一次队，最后被告知“下午来”或者“明天来”。

第三天，他怀里攒了四张结果：血的、片的、B超的、痰的。只剩心电图。

做完心电图，他抱着五张纸站在走廊里发愣。五张纸，五个科室发的，五个地方取的，上面印着五套不同的条码。他想起大夫说过“查完再来找我”，可大夫今天不坐诊，明天才在。

他在长椅上坐了很久。纸捏在手里，被汗浸软了。他不知道这五张纸该往哪儿送，也不知道它们凑在一起是什么意思。他甚至不知道，自己这三个月，是病着，还是没病着。

第二天，他挂了个号，进呼吸科三诊室。

坐诊的是位老大夫，头发白得匀，桌上的茶杯见了底。他接过五张纸，没急着看，先把它们一张一张铺在桌面上，铺成排。桌子小，五张纸有些叠着，他就挪茶杯，挪笔筒，硬是让它们各占一块地方。

然后他不说话了。眼睛从第一张移到第五张，又移回来。诊室门口有人探进头，他抬手示意，等一等。

大约三分钟，他拿起笔，在第五张纸上圈了一个数，又回头在第一张上画了个箭头，箭头指向第二张。

“你这咳，不是肺的事。”他说。

老周愣了：“片子上不是有阴影？”

“有，良性的。”老大夫把第二张和第五张并在一起，“你看这里，心电图上这个，和你血里这一项，是一回事。你夜里躺下就咳，坐起来轻，对吧？”

老周点头。

“那不是肺，是心。”

老大夫说，五张单子，是五个人从各自的角度拍了半张脸。验血的人只看见血，拍片的人只看见片，谁都没错，可谁也没看见老周。得有人把五张纸摊在同一张桌上，朝着一个人看。

老周听不太懂，只问：“那我要挂心内科？”

“我给你转。一次就够，别让你再跑五趟。”

老周出门时回头看了一眼。五张纸还铺在桌上，老大夫低头写着，笔尖压着它们，像压着一件已经缝好的东西。

三个月后，老周在街上碰见那位老大夫，没敢认。回家跟儿子说起，说那大夫不像看病，像在拼图。

后来电视里讲什么“一个窗口办完”“数据多跑路”，老周听不懂那些词，只跟儿子说：“就该这样。五张纸，摊一张桌上。”

他不知道，那天三诊室桌面上那三分钟，早有人给它起过名字。

## 原来讲的是……

**概念：整体性治理**

## 概念解释

整体性治理（Holistic Governance），由英国学者佩里·希克斯（Perri 6）与帕却克·登力维（Patrick Dunleavy）在二十世纪九十年代末提出，是针对新公共管理改革所导致的机构分割、职能碎片化与服务割裂而提出的一种再整合理论。其核心主张是：政府应以公民需求而非自身职能分工为组织依据，通过协调政策、整合机构、再造流程，使分散的部门“像一个整体”那样运作。

理解这一概念，要害在于一个“分”字带来的问题和一个“合”字提出的解法。

二十世纪八十年代以来，新公共管理运动在西方国家广泛推行，强调分权、市场化、合同外包与结果导向。它确实提升了单个部门的效率，却也带来一个副作用——政府被切成了许多互不连通的条块。一个公民要与政府打交道，往往需要在多个部门之间反复奔波，反复提交同样的材料，反复说明同样的情况。希克斯等人指出，这种碎片化造成的浪费、重复与信任损耗，其代价可能超过专业化带来的收益。因此他们主张“逆碎片化”：不是把每个部门做得更小更强，而是让它们之间能够对接。

具体机制包括三类。一是机构层面的整合，如大部门制，把职能相近的机构合并；二是服务入口的整合，如一站式服务，让公民在一个窗口完成多部门事项；三是信息与流程层面的整合，如跨部门数据共享与业务重组，使数据在后台流转，而不是由公民在前台搬运。

这里需要特别澄清一个常见误解：整体性治理**不等于机构越大越好**。合并机构只是手段之一，真正的核心是协调机制——能否围绕一个公民的完整需求，把不同部门的判断放到同一张桌子上。如果机构合并了而内部依旧各管一摊、各说各话，那只是把碎片装进了同一个盒子，碎片仍然是碎片。

在公共管理与公务员考试语境中，这一概念的重要性体现在两个层面。理论层面，它是对新公共管理“分权化、合同化”倾向的反思与纠偏，代表公共管理范式从“效率导向的分工”向“需求导向的整合”的转向。实践层面，它是理解当代中国多项改革的钥匙：“一网通办”对应流程再造与信息共享；“大部门制”改革（如组建国家市场监督管理总局，整合原工商、质检、食药监等职能）对应机构整合；“跨省通办”则是跨层级、跨地域的协调机制建设。申论中凡涉及“放管服”“优化营商环境”“基层减负”“群众办事难”，其分析框架都可由此切入。

现实案例一：上海市“一网通办”改革。早期做法多是把线下窗口搬到线上，用户仍需在不同部门的系统之间跳转。后续推进“一件事”集成服务，例如“开办企业一件事”，将营业执照、刻章、税务登记、社保开户等环节整合为一个流程，申请人只提交一套材料。这不是简单地把部门网站链接起来，而是以企业生命周期为依据重构了服务链条。

现实案例二：京津冀异地就医直接结算。过去患者异地就医需先垫资、再拿票据回参保地报销，往返多次。改革后在制度层面打通各地医保信息系统、统一结算规则，患者只面对医院一个窗口。这里的难点不在技术，而在各地政策标准、基金管理和监管责任的协调——恰恰印证了整体性治理的着力点在于协调机制而非组织规模。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 五张分属不同科室的化验单 | 分散在各部门的政策与信息 | 每一项都有专业依据，单独看并无错误 |
| 每张单子都要重新交费、重新排队 | 碎片化带来的重复成本 | 公民在部门之间往返所承担的交易成本 |
| 老周抱着单子在走廊里发愣 | 公民面对碎片化服务的无力感 | 个体无法整合分散信息，也判断不出整体意义 |
| 五张纸被摊在同一张桌上 | 跨部门协调与信息整合机制 | 关键动作不是合并机构，而是建立共同审视的平台 |
| 老大夫挪开茶杯与笔筒腾出位置 | 整合所需的组织让渡与流程腾挪 | 整合需要各环节为整体判断让出空间 |
| 箭头从第一张指向第二张 | 跨部门信息关联与因果判断 | 单张数据没有意义，关联之后才产生诊断价值 |
| “我给你转，一次就够” | 一站式服务与流程再造 | 以服务对象一次办成为目标，而非以职能划分为终点 |
| 老周说“像在拼图” | 以公民旅程为组织依据 | 从使用者视角才能感知到整体性 |

## 公务员考试视角

**行测常识**：可能以“大部门制改革”“一网通办”等具体改革为题干，考查其理论依据；也可能反向考查“整体性治理区别于新公共管理的核心主张”，正确答案通常落在“协调与整合”，而非“分权与竞争”。

**申论**：材料常给出群众办事多环节跑动的具体案例，要求概括问题或提出对策。答题时应避免止步于“加强宣传”“提高效率”，而应写出“以群众需求为导向重构流程”“推动跨部门数据共享与业务协同”“建立跨层级协调机制”等表达。

**结构化面试**：常见于综合分析题与组织管理题，如“如何看待某地推行一件事一次办”。可用“整合—协调—结果导向”三层作答结构，并注意点明：整合不是简单合并机构，而是围绕服务对象重塑流程。

## 思考题

1. 老周在长椅上那段犹豫，故事只写了“他不知道这五张纸该往哪儿送”。如果他当天分别把五张结果送回五个科室，结局会有什么不同？
2. 老大夫为什么先挪茶杯和笔筒，而不是先看单子？这个动作被写成一个细节，你认为它省略了什么？
3. 转折只发生在诊室里短短三分钟，而老周已经跑了三天。这三天是否白费？如果重来一次，应该从哪一个环节开始改变？
