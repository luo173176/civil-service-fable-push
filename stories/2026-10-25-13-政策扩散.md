# 钟声响到第几条街

## 寓言故事

光绪三十一年冬，清溪镇西街起火。火烧了十九间屋。救火的人从河埠头排到火场，水桶传到第三十个人手上，只剩半桶。

绸庄东家沈广泰住在东街，隔一条河，只闻到焦味。开春他出银八百两，在东街口起一座钟楼，两丈四尺高，楼上挂一口从宁波买来的铜钟；楼下腾出一间屋，放四架水龙、二十支火钩、三十条麻袋。他雇更夫阿六，夜里每半个时辰上一趟楼，见火就敲钟：一下东街，两下西街，三下河南，四下河北，连敲是火已烧到河边，各家撑船来接。

头一年，街坊说他钱多烧的。第二年钟响过两回，都是虚惊：一回是哪家灶屋冒黑烟，一回是猫上了房。茶馆里有人笑，八百两银子买一口钟，不如多买两口棺材。

第三年开春，米行周德茂来了。他在钟楼下站了半天，问阿六：“你夜里睡哪里？”阿六说睡楼上，铺盖卷就在钟底下。又问：“一个月多少钱？”阿六说三百文，东家管一顿夜饭。

周德茂回去就动工，在米行后巷起了一座一丈八的小楼，比东街矮六尺。他说东街楼高，是要望见河对岸，我这条后巷用不着。钟也买不起，他从废船上拆了一段铁轨，挂起来用铁锤敲，声音闷，传得倒远。他还添了东街没有的一样：楼底埋一口大缸，常年蓄水，缸边搁十二只木桶，桶上写各户姓名，谁家起火，谁家的桶先动。

镇上先笑他学样，后来算账，发现他那个便宜。第四年，河南、河北两条街各起一座。第五年，药铺、酱园、锡匠行三家合起来，在河埠头又起一座，钟是旧的，从庙里化的。

秋后，县里张知县下乡查团练，看见四座楼，回去下了札子：全镇十二坊，每坊须设火警一楼，经费自筹，年底查验。

札子传到南栅，里正老蒯犯了难。南栅最穷，凑了两个月凑出四吊钱，起不起楼，买不起钟，就在土地庙廊下挂了面破锣，派一个半瞎的老汉守着。老汉守了七天，第八天病了，锣让小孩偷去换了糖。

腊月里南栅起火。没有人敲锣，锣已经没了。有人喊，喊的时候火上了房梁。烧了四间。

开春阿六去南栅送火钩，东街多备的。老蒯蹲在烧黑的墙根下说：“我也挂过锣的。”阿六说：“锣是死的。你挂锣那天，谁教过你，夜里什么时候该到廊下看一眼？”

后来清溪镇修志，把这几座楼记在“公所”一门。修志的是张知县带来的幕僚，姓吴，从前在江宁办过巡警。他写：火楼之设，始于沈氏，盛于周氏，成于官令，而败于南栅。写完停了笔，又添一句：法之立也，有器、有主、有时、有验，四者去一，器存而法亡。

那年沈广泰六十九，眼睛花了，每日午后还上钟楼坐一个时辰。孙子从上海读书回来，问他：“爷爷，人家都盖了，你还守着做什么？”

沈广泰说：“我不是守钟。我是守头三年。”

吴幕僚那句“始于、盛于、成于”，后来被一个美国人用一条曲线画了出来。他叫罗杰斯，一九六二年写《创新的扩散》：新做法在人群与组织之间的传播，起初慢，中间陡，末了平，像一枚拉长的 S。一九六九年，沃克把这条曲线搬到政府之间，称之为政策扩散。

**概念：政策扩散**

## 概念解释

政策扩散（policy diffusion），指一项政策创新——新的制度安排、政策工具或治理做法——随时间经由政府间渠道从一个辖区传播到另一个辖区，并被后者采纳的过程。它回答的不是“某地为什么出台某项政策”，而是“为什么相似的地方先后出台了相似的政策”。

它成立需要几个条件。其一，存在可识别的创新源，即某个先行辖区先做了别人没做的事；其二，存在政府间的传播通道，横向如邻近地区、同级政府、官员往来、媒体报道与考察学习，纵向如上级部署、财政转移支付、立法与考核；其三，采纳决策同时受内部因素（财政能力、问题严重程度、辖区特征）与外部因素（邻居是否已采纳、上级是否要求）影响，这也是贝里夫妇（F. S. Berry & W. D. Berry）在二十世纪八十年代区分“内部决定模型”与“扩散模型”的由来；其四，扩散的结果通常不是原样复制，而是“再发明”（re-invention），采纳者会依本地条件改造政策内容。

时间上最典型的特征是 S 形曲线：早期采纳者稀少而缓慢，因为风险高、信息少、要承担试错成本；过了某个临界点后加速，因为信息外溢、邻近压力与竞争加剧；后期趋于平缓，剩下的要么能力不足，要么问题本身不适用。

机制上通常区分四类。学习：观察他地的实施效果与失败教训，据此推断因果，改进本地设计。模仿：未必评估效果，而是因为“看起来正当”“别人都有”而采纳，容易只取形式。竞争：面对招商引资、人才流动、区域排名等压力，地方政府相互攀比，甚至出现放松标准、向下竞争的“趋劣竞争”。强制：上级通过命令、考核、财政条件、立法要求推动下级采纳，速度快但可能压制地方信息优势。

中国的“试点—总结—推广”是政策扩散的典型制度安排，韩博天（S. Heilmann）称之为“分级制试验”：先在有限范围试点，允许地方变通，成功则上升为全国性或区域性政策，失败则就地终止。干部交流、挂职、对口支援、党校培训同样是隐性的扩散通道。

现实案例俯拾皆是。河长制：2007 年无锡因太湖蓝藻事件首创，此后江苏、浙江等地陆续跟进，2016 年中办、国办印发《关于全面推行河长制的意见》，2018 年底全国建立河长制，正是“地方首创—邻近学习—中央确认—全面推开”的完整链条。自贸试验区：2013 年上海首批设立，此后分批扩容，各自贸区累计形成数百项制度创新成果并向全国复制推广，其中有大量本土化再发明，如内陆自贸区的多式联运、边境自贸区的互市贸易。再如浙江“最多跑一次”改革，2016 年提出后经中央推广演化为“一网通办”“跨省通办”，各地在数据共享范围、窗口设置上差异明显，效果也参差。

最常见的误解是“扩散快等于扩散好”。采纳率上升只说明形式被接受，不说明机制被移植。若只学到了招牌、机构与文件，没学到人员、流程、经费与问责，结果就是器物齐备而制度空转——清溪镇南栅的破锣就是这种结局。

| 沈广泰出八百两建东街钟楼 | 先行者承担试错成本 | 首创者支付信息成本与失败风险，头两年被讥为“钱多烧的” |
| 头两年虚惊与茶馆嘲笑 | 早期扩散缓慢的原因 | 效果未获验证，潜在采纳者观望，采纳率低 |
| 周德茂登楼打听、问更夫睡哪里 | 学习机制 | 不只问“建什么”，更问“怎么运转”，触及机制而非外形 |
| 拆废船铁轨、矮六尺、蓄水缸与写名木桶 | 本土化再发明 | 依据本地条件改造，成本更低、动员更实，非原样照搬 |
| 第四五年河南河北、药铺酱园纷纷起楼 | 模仿与竞争，S 形中段加速 | 邻近压力与信息外溢叠加，采纳率陡升 |
| 张知县下札子，十二坊一律设楼 | 强制机制（纵向推动） | 命令式扩散速度快，但压缩了地方适配空间 |
| 南栅只挂破锣、无人守夜 | 只学形式未学机制 | 器物到位而人员、时序、演练缺位，采纳不等于有效 |
| 南栅烧了四间 | 扩散质量与形式主义风险 | 表面采纳率百分之百，实际治理能力为零 |
| 阿六说“锣是死的” | 政策执行与机制要素 | 关键在值守、时序与责任，不在器物本身 |
| 沈广泰“我是守头三年” | 先行者的隐性贡献 | 试错积累的知识与信任，是后来者免费获得的公共品 |
| 全镇十二坊皆设楼后归于平静 | S 形曲线的饱和段 | 累计采纳率趋平，剩余空间有限 |

## 公务员考试视角

行测常识可能以“某地首创某制度后被全国推行”为题干，考查政策过程的环节、政府间关系的类型，或直接辨析“政策扩散/政策转移/政策学习”的区别；也可能出现在判断题里，如“扩散速度越快，政策效果越好”，属典型错误项。申论常给一组多地推行同一改革但效果参差的材料，要求概括问题、分析原因、提出对策，答题落点应在“重形式轻机制”“缺乏配套与考核”“照搬不适应本地条件”上，并可用“试点—总结—推广”“因地制宜再创新”“避免一哄而上”等表述。结构化面试中可能问“某地经验被广泛推广后效果不佳，你怎么看”，答题结构宜为：肯定扩散的积极意义—指出形式化采纳的症结（人、财、流程、问责缺位）—提出分类推广、先试后推、结果评估的对策。

## 思考题

1. 沈广泰说“我不是守钟，我是守头三年”。这三年里他实际生产出的是什么？为什么后来者可以免费拿走，而南栅却拿不走？
2. 周德茂改矮了楼、换了铁轨、加了水缸。如果当初他把钟楼一模一样照抄，后来的四条街还会跟进吗？这说明扩散中的“再发明”起到什么作用？
3. 张知县的札子让十二坊在一纸之内全部“建成”。若你是吴幕僚，除了“器存而法亡”，还会在这句话前面补上哪几条查验标准，才能避免第二个南栅？
