# 账本比庄园晚到一步

## 寓言故事

陈老爷在省城有铺子，乡下的三百亩水田和一片茶山，交给远房侄子陈守田管。契约写得清楚：每年秋后，守田交粮四百石、茶银八十两，余下的归他。

头三年，守田交得爽快。第四年起，粮数没少，但陈老爷总觉着不对——庄园送来的账，字迹越来越潦草，条目越来越少。他问一句，守田回三句，句句在理：虫害、旱情、佃户跑了两户、茶山换苗。陈老爷在省城的算盘打不到乡下，只能点头。

第七年，陈老爷回乡祭祖，顺路去茶山看。山下遇见挑柴的老佃户周伯。周伯绕着他走了半圈，忽然说：“老爷，您家的茶，去年出了三千斤。”

陈老爷心里一沉。账上写的是八百斤。

他没急着问罪，先到镇上茶行坐了半日。掌柜翻出旧单子：陈家茶山七年，年年出茶两千斤上下。陈老爷拿着那几张单子回庄园，守田跪在堂下，还是那套话：虫害、旱情、换苗。陈老爷把单子摊开，守田不说话了。

陈老爷当晚就想换人。可换谁？族里几个后生，不是没管过田，就是跟守田一路货色。请个外姓管家，佃户不认，村中长老也要说话。他这才明白，自己手里那本契书，管得住租数，管不住守田每天做什么、买什么、卖什么、对谁说真话。

第二年，陈老爷改了规矩。他不再只写“交粮四百石”，而是写：

一、每季账目一式两份，一份送省城，一份交村中耆老会过目，两处对不上，以耆老会的为准。

二、茶山每年新苗、雇工、采制，由佃户推举两人同去验看，签字。

三、交足额定之外，每多出百斤茶，守田分三成，不用报账；若查出隐匿，罚没全部私留。

四、陈老爷每两年回乡一次，住在庄园，不走。

守田看完，沉默很久，问：“那耆老会的茶钱谁出？”

陈老爷说：“我出。”

这四条执行了五年。守田仍会盘算自己的好处，但盘算的方式变了：他得多产茶，因为多出的三成是自己的；他得把账说实话，因为两本账对不上就要出丑；他得让佃户愿意替他说话，因为佃户推举的人要去验苗。

陈老爷后来对儿子说了一句话，儿子记了三十年：“账本比庄园晚到一步，那是我的错，不是守田的错。我让他管庄园，却没让他愿意跟我说真话。”

那年冬天，陈老爷在省城书房里翻出一本旧书，夹着半页纸，上头写着一行小字，旁边有铅笔批注——那是他早年跟一位洋学堂教习学的词。他看了很久，把纸折起，压在算盘底下。

多年后，他儿子陈维桢考进省立学堂，念的是政治科。课上先生讲到一个词，他忽然想起父亲那本旧账。散课后他回书房，翻出算盘底下那半页纸，纸已经发黄，上面写着：

“委托人—代理人”。

## 原来讲的是……
**概念：委托代理理论**

## 概念解释

委托代理理论研究的是这样一种关系：一方（委托人）把事务或决策权授予另一方（代理人），由代理人为委托人行动。这个看似简单的安排里藏着三个要件，缺一不可。

第一，目标函数不一致。委托人想要的结果与代理人想要的结果不完全重合。陈老爷要的是庄园长期产出最大化，守田要的是自己手里落下的银子。两者并非全然对立——守田也想过庄园好——但在关键处会分叉。

第二，信息不对称。代理人掌握关于行动、成本、环境的私人信息，委托人只能观察到部分结果，甚至只能观察到被代理人筛选过的结果。陈老爷在省城，庄园的事他靠账本；账本由守田写，送得比庄园发生的事晚一步。这一“晚”，就是信息租金的来源。

第三，责任不可完全契约化。契约能写明交多少粮、多少茶银，写不清守田每天巡不巡田、对佃户公道不公道、遇旱先救哪块地。凡不能写进契约的部分，代理人就拥有事实上的自由裁量空间。

在这三个条件下，代理人会倾向采取对自己有利、对委托人未必有利的行动，这就是道德风险；委托人为了减少损失，要设监督、要查账、要对齐激励，这就是监督成本与激励成本。委托代理理论的核心命题不是“人坏”，而是“制度安排决定了自利行为的方向”。因此解法不是道德说教，而是激励相容：设计一套规则，使代理人说真话、干实事、多产出恰好成为他的最优选择。陈老爷后来的四条规矩，本质上是把守田的收益与庄园的长期产出挂钩，把信息分散到耆老会与佃户手里，再用不定期回乡打破“天高皇帝远”的空间屏障。

理论源头可追溯到二十世纪六七十年代。斯蒂格勒、阿罗等人在信息经济学中提出相关问题，罗斯（Stephen Ross）在一九七三年正式使用“委托—代理”这一表述，詹森与梅克林一九七六年的论文把代理成本分解为监督成本、约束成本与剩余损失，使其成为公司治理的标准工具。随后，政治学与公共行政把它引入政府研究：选民选议员、议员授权内阁、内阁委托部委、部委交给地方、地方压到基层——每一层都同时是下层的委托人、上层的代理人。链条越长，信息损耗越大，目标偏移越常见。

这也是它在公共管理与公务员考试中格外有用的原因。中央与地方关系里，“一放就乱、一收就死”很大程度是激励与信息结构的问题：地方掌握一线信息，中央难以完全观察地方行动。政府与国企之间，出资人目标（保值增值、公共服务）与经营层目标（规模、在职消费、短期业绩）可能背离，于是要有考核、审计、薪酬与任期制度。业主与物业之间，业主大会难组织、服务难计量、账目难核查，同样是典型结构。申论里的“信息壁垒”“最后一公里”“数字政府”“基层负担”，用这个框架分析，往往比空谈作风更扎实。

需要警惕的常见误解是：这不是管理学鸡汤。它有成体系的模型、严格的假设与可检验的推论。它不说“人应当忠诚”，它说的是：在信息不对称与目标不一致下，忠诚不能被默认，必须被制度生产出来。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 陈老爷 | 委托人 | 拥有庄园所有权，把经营权授予代理人，但远离现场 |
| 陈守田 | 代理人 | 掌握庄园日常信息与自由裁量权，其收益与委托人目标部分分叉 |
| 账本比庄园晚到一步 | 信息不对称 | 委托人只能事后、间接、被筛选地观察代理人行动 |
| 契约只写“交粮四百石” | 责任不可完全契约化 | 可计量的产出能写，努力、公道、用心等不可写 |
| 守田报八百斤、实出三千斤 | 道德风险与隐匿 | 代理人利用信息优势谋取私利，偏离委托人利益 |
| 陈老爷回乡查账、请茶行对单 | 监督成本 | 委托人必须付出额外成本才能逼近真实信息 |
| 耆老会与佃户验苗 | 信息分散与第三方核验 | 用多方知情者稀释代理人的信息垄断 |
| 多出百斤分三成 | 激励相容 | 让代理人的自利与委托人的长期产出同向 |
| 陈老爷两年回乡一次 | 打破空间与层级距离 | 减少层层代理造成的信息损耗 |
| 旧书里“委托人—代理人”半页纸 | 概念揭晓 | 故事结束处才点出理论名称与学术来源 |

## 公务员考试视角

行测常识部分，若考经济学或管理学流派，可能以“詹森与梅克林”“代理成本三分解”“罗斯首次使用委托代理一词”等形式出现；也可能借“信息不对称”与逆向选择、道德风险并列设问。申论中，涉及国企改革、基层治理、政府购买服务、物业纠纷、数字监管的材料，用“目标不一致—信息不对称—责任难契约化”三要件拆题，再以“激励相容、信息共享、第三方核验、减少层级”四类对策收束，层次会比抒情式作答清晰得多。结构化面试里，题目若问“如何让政策不折不扣落地”“怎样调动基层积极性”，可以先用该框架点出问题的结构性根源，再落到具体机制，避免一开口就是“加强思想教育”。

## 思考题

1. 陈老爷后来定的四条规矩里，哪一条直接针对“信息不对称”，哪一条直接针对“目标不一致”？如果把其中一条删掉，守田的行为可能怎么变？
2. 故事里周伯和耆老会都起了作用。如果村里没有周伯这样愿意开口的人，陈老爷还剩下哪些办法逼近真实信息？
3. 陈老爷“每两年回乡一次”这种办法，在中央与地方、政府与国企的关系中不可能完全照搬。现实中有哪些替代性机制在做同样的事？代价是什么？
