# 渠成之后

## 寓言故事

那年大旱，石头村的井见了底。岩匠四十岁，手上全是凿子磨出的茧，他领着四十个汉子进后山，要把龙泉的水引过来。

渠走了七里，绕三道梁，最险的一段挂在崖上，人得用绳子吊着凿。死了两个。第二年春天水下来了，头一股冲进村口的干塘，塘底的裂泥泡开又合上，几个女人蹲在塘边哭。

水到哪儿，人就往哪儿搬。先是渠首几户把房子挪到渠边，接着渠尾搭起豆腐坊，何婶的婆婆用渠水点卤，说这水做的豆腐能立住筷子。再后来，渠两岸支起二十七个摊子，逢五赶集，卖菜的、补锅的、剃头的都有。学校也搬到了渠尾，那儿地平整。

二十年过去，石头村的地界没变，形状变了——一条水线串着两条街，村口的老槐树反倒成了村外。

县里来了人，说要修水库。水库一修，南坡要淹，渠得改道北坡。技术员小岑摊开图纸，红铅笔从渠首画到渠尾，笔尖停住——那儿密密麻麻画了二十八个方块。

“这二十八户得迁。”

岩三听着。他是村主任，也是岩匠的儿子。他爹现在瘫在床上，喉咙呼噜呼噜说不成句，手指还能敲，敲在床板上，是当年凿渠的节奏：一下，两下，停，再一下。

小岑说，改渠是为了下游三个乡。岩三说我知道。小岑说，补偿按户算，一户三万。岩三说，何婶家豆腐坊一年挣的就不止三万。小岑不说话了。

会开在渠边的晒谷场上。何婶说，我家三代在这渠边。老周说，我的菜地是渠水浇出来的。老师说，迁学校，孩子得多走五里。有人问岩三：你爹当年修渠，是为了今天让人把渠挖了？

岩三一夜没睡。他沿渠走，摸着壁上那些凿痕——哪一段是他爹凿的，哪一段是爹的兄弟凿的，哪一段凿穿了石头渗了血，他都认得。摸到渠尾，就是那二十八个方块的地方。

第二天他去了县里，签了字。

但他提了三条：新渠先修通，再迁人；新渠两岸的地，按老渠的户头分；迁走的二十八户，回迁优先。小岑问，为什么这么算。

岩三说，你以为你在改渠，其实是渠在改你。

小岑没听懂。

新渠修了两年。迁房那天何婶哭了一路，磨盘用板车拉，拉到北坡，她舀了一瓢新渠的水，尝了尝，说比老的甜——其实是同一股水。

又过五年。北坡的渠两岸长出两条街，二十多个摊子，一所学校。赶集还是逢五。

岩三的儿子从省城回来，站在北坡渠边忽然不动了。他数摊子，二十六个，摆法和老渠那边一模一样，连何婶家的豆腐坊都在同一个拐角。

晚上他问他爹：当年改渠，到底是县里改的，还是村里改的？

岩三削着一根竹子，削了半天才说：都不是。渠修好了，就不归修渠的人了。

**概念：政策反馈效应**

## 概念解释

政策反馈效应（policy feedback effect）由美国政治学家保罗·皮尔逊（Paul Pierson）在 1993 年发表于《世界政治》的论文《当结果变成原因：政策反馈与政治变迁》中系统提出，核心命题可以压成一句话：政策制造政治（policies create politics）。一项政策出台，通常被理解为一个政治过程的终点；皮尔逊要说明的是，它同时是下一个政治过程的起点——政策会回过头来重塑利益格局、公众认知和制度能力，从而规定后续政策“能怎么改、改得动多少”。

**先把它和政策评估分开。** 政策评估是回头看：目标达没达到、钱花得值不值、有没有副作用。政策反馈是向前看：这项政策落地之后，把政治场上的玩家、观念和规则改成了什么样。同一个“回头看”的结论，可能完全不同；但反馈关心的是另一件事。所以常见误解是把两者混为一谈，用“效果好不好”去解释“为什么改不动”——效果好，未必改得动；效果差，也未必改得动。

**反馈要生效，政策得留下痕迹。** 学界一般强调三个条件：一是持续性，政策要长期存在，人们才有时间围绕它调整行为；二是显著性，政策的好处与成本要能被受益人直接感知，看得见、摸得着；三是规模，覆盖人群足够大，才可能形成可组织的群体。临时补贴、小额试点、隐蔽的税收优惠，反馈就弱；普惠性养老金、医保、学区划分、户籍，反馈就极强。

**两条主干机制。** 其一是资源效应：政策分配利益，也分配组织能力。一项政策养出稳定的受益者群体，他们有了钱、有了闲、有了共同身份，就会组织起来捍卫它——美国的老年协会、中国的各类行业协会，都是这样长出来的。其二是解释效应：政策改变人们对“什么是正常”的判断。国家一旦兜底养老，人们就不再认为养老只是家事；一旦习惯了医保报销，看病自付全款反而成了异常。预期一旦被政策重写，退回原状在政治上就几乎不可行。晚近研究还补了第三条：制度效应，政策会顺手造出执行它的机构、队伍、统计口径和考核指标，这些组织本身就是政策的捍卫者。

**由此产生路径依赖。** 政策不是画在白纸上的图，而是在自己修的路上开车，方向盘还焊死了一半。后来的每一笔投入都叠加在前一笔之上，改动的成本随时间上升，这就是所谓“积重难返”——它不是一个道德判断（“既得利益集团太坏”），而是一个制度事实：旧政策已经把社会本身重新塑形了一遍。

学术脉络上，熊彼特式的洞察早有先声：沙茨施奈德 1935 年的《政治、压力与关税》就指出关税一旦立起来，受益者会围绕它重组政治；洛维 1964 年提出“政策决定政治”。皮尔逊之后，斯科克波尔、梅特勒、索斯、坎贝尔等人把它做成了实证研究纲领，坎贝尔的《政策如何造就公民》就展示了美国社保如何提高了老年群体的政治参与。

中国语境里这类现象并不稀罕。计划生育政策在几十年间不只是控制出生，还塑造了一代人的生育观念、一支基层计生队伍、一套考核与统计体系；转向二孩、三孩时，机构要重组、口径要调整、观念已成惯性，政策转身比政策出台慢得多。另一个例子是城乡居民医保：2003 年新型农村合作医疗建立后，农民对“看病能报”形成稳定预期，此后每次调整筹资标准、整合城乡制度，都必须处理既有参保人的心理账户和基层经办能力。再如开发区与地铁选线：一旦建成，沿线的土地开发、产业布局、人口分布都已围绕它展开，改线就是迁半个城。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 大旱中决定引龙泉的水 | 政策的初始出台 | 为解决当下问题的一次性决定，当时并未预料它的长期后果 |
| 渠的走向、长度与三道梁 | 政策的制度形态 | 一旦定型，规定了资源流向，也规定了谁被覆盖、谁被排除 |
| 迁到渠边的二十八户、何婶的豆腐坊、二十七个摊位 | 受益者群体的形成（资源效应） | 政策分配出的利益把人固定在了特定位置上，成为改革的对手方 |
| “这水做的豆腐能立住筷子”、逢五赶集、学校迁到渠尾 | 认知与惯例的改变（解释效应） | 人们对“日子本该是什么样”的预期被政策重写，不必谈钱也在起作用 |
| 渠壁上的凿痕、坟一样的旧渠 | 沉没成本与路径依赖 | 后来的投入层层叠加在旧政策之上，改动成本随时间上升 |
| 改道北坡的图纸与一户三万的补偿款 | 改革方案与补偿的有限性 | 用一笔一次性的钱去兑换长期制度收益，通常兑不动 |
| 岩三签字但提三条：先通后迁、按老户头分地、优先回迁 | 改革策略：新老划断、过渡期、增量换存量 | 承认旧政策的既成事实，用安排而非否定来推动调整 |
| 北坡新渠两岸又长出同样的街市 | 反馈的再生产 | 新政策同样会制造新的受益者与新的预期，循环不因一次改革而终止 |
| 岩三那句“渠修好了，就不归修渠的人了” | 政策自主性 | 政策作者在政策落地后即失去对它的支配权 |

## 公务员考试视角

行测常识可能以“政策制定与执行”类题目出现，考查对政策过程双向性的理解，比如判断“政策只是政治过程的输出”这一说法是否正确。申论更可能给一份“某地旧政策难调整”的材料——老旧小区加装电梯、开发区转型、医保并轨、撤并校点——要求分析阻力来源。此时只写“既得利益阻挠”“群众观念落后”属浅层；写出政策自身塑造了受益群体、重写了公众预期、生成了执行机构，才算摸到政策根源，对策也才能落到过渡期安排、新老划断、补偿与增量设计上。结构化面试常问“一项好政策推不动，你怎么办”，答题时应先辨明阻力是来自方案缺陷还是来自旧政策的自我再生产，再谈沟通、试点、补偿、时序。这一概念能显著提升分析的层次感。

## 思考题
1. 岩三为什么坚持“先修通新渠，再迁人”？如果把这两件事的顺序倒过来，何婶和老周在谈判中的位置会有什么不同？
2. 故事里哪些细节属于“解释效应”而非“资源效应”？请找出至少两处不涉及钱的描写，说明它们如何改变了村民对“什么是正常”的判断。
3. 北坡新渠两岸又长出了同样的街市。如果你是县水利局下一次改渠的规划者，会在设计阶段预先做哪些安排，以免重演“迁半个村”？
