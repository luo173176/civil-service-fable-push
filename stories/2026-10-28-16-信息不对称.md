# 摸不出来的毛病

## 寓言故事

周老栓五十二岁，头一回自己买牲口。儿子年底娶亲，四亩地缺一头能拉能驮的。老伴把攒了六年的钱缝进蓝布带，缠在他腰上，三百块整。临出门撂下一句：钱没了牲口也没了，你也别回来。

镇东干河沟的集，牲口拴成两排。老栓从东口进，第一眼看中一头黑骡。四岁口，毛色油亮，鬃毛剪得齐整，蹄子扣过油，日头一照发青。卖主姓韩，四十来岁，话不多，只说牙口嫩、性子稳，套车拉犁都成。老栓围着转三圈，掰嘴看牙，摸脊背，提蹄子。经纪老赵在旁边撮合，说韩家这骡子在他手里过了眼，出不了岔。老栓问能不能使唤一圈。姓韩的看了看日头，说草沟里走两步吧，后晌还得赶回去。老栓牵着走了两个来回，起步稳，不惊不躁，缰绳一抖就走，一勒就停。

二百八十块。老赵抽了两成。

牵回家第二天早晌，骡子不吃料，只拿鼻子拱槽。老栓以为是换了槽不惯。第三天套车拉粪，出村没半里，骡子忽然站住，两肋一起一伏，鼻子里嘶嘶地响，像只漏风的风箱。卸了车，歇半个时辰，又好了。再套，再喘。老栓请来兽医。兽医听罢脊背、摸罢肋，说了一句：这毛病不是三天两天了，轻载看不出来，重载才现，卖的人心里有数。

老栓揣着气赶下一个集。韩家那个位置空了。老赵的棚子还在，听罢摆摆手：“老哥，货一出手，钱一过手，当面看清了才成；你没看出来的，我怎么替你担？”老栓要凭据。老赵笑：“咱这儿，一句话就是凭据。”

骡子后来叫邻村一个屠户折价牵走了，一百一。老栓在家躺了两天。

转过年来，老栓又要买驴，这回带上邻村的吴老六。吴老六使了三十年牲口，摸一把蹄窝、看一眼眼角，能说出这畜生平素使的什么套。到了集上，吴老六看中一头灰驴，不急着讲价，先问：这驴你自家使的是什么活？卖家说，磨坊，拉磨。吴老六说那成，套车我试一晌。卖家痛快，把车套上，往漫坡走一趟，回来又往硬地里拉一趟，来回一个多时辰。

价钱讲定，老栓要牵走。吴老六按住他，回头对卖家说：“咱写个条子：七天之内，拉车不吃力、夜里不惊栏，钱退你，驴我还你。敢不敢写？”卖家沉吟片刻，说敢。

老栓不识字。那张黄纸由吴老六念了两遍，画了押，揣在贴肉的褂子兜里。

许多年后，老栓的儿子在县里管市场，吃饭时说起如今买卖要明码标价、可退可换、留个凭证。老栓夹了一筷子腌菜，说：“当年我要是有那张黄纸，二百八不至于剩一百一。”儿子想了想：“您那回吃的亏，一半在姓韩的不老实，一半在——您看得见毛色，看不见那口气。”老栓愣了一下，说这句倒像话。他放下筷子，忽然又添一句：“可你说，吴老六那样的，一个集上能有几个？”

## 原来讲的是……

**概念：信息不对称**

## 概念解释

信息不对称，指交易双方对交易标的、彼此状况或未来行为所掌握的信息不均衡：一方知道得多，一方知道得少，而把真相核实清楚的成本高到不可能为零。它成立有两个关键条件：一是信息本身有价，且分布不均；二是验证困难——买方即便心存疑虑，也难以在成交前把底细摸透。

按发生时点，它分成两段。**事前的逆向选择**：卖方知道质量，买方只知市面上的平均质量，于是只肯按平均价出价；质量好的一方觉得吃亏，退出市场；剩下的次品把平均质量进一步拉低，买方预期再降、价格再降，又挤出一批较好的货。如此循环，劣品把良品赶出市场。阿克洛夫1970年发表《柠檬市场：质量的不确定性与市场机制》，用二手车市场证明这一过程可能使市场萎缩甚至消失——“柠檬”在美式英语里指外表光鲜、内里糟糕的旧车。**事后的道德风险**：合约签订之后，一方的行为难以被观察——是否爱惜车辆、是否按时还款、是否认真经营——当事人便有动机把成本转给对方承担。

针对这两段，经济学给出的不是道德劝诫，而是机制设计。**信号发送**由斯宾塞提出：掌握信息优势的一方，主动付出一种高成本、且劣质者难以模仿的代价，把自己与劣质者区隔开来——质量担保、品牌投入、学历文凭都是这一类。**信息甄别**由斯蒂格利茨提出：处于信息劣势的一方，设计出不同的合约选项，让对方的选择自动暴露其私人信息——保险公司的体检与差别费率、招聘的试用期、银行的抵押要求都是这一类。三人的工作共同获得2001年诺贝尔经济学奖。

公共管理中的许多制度，本质上是压缩信息差的装置。行政许可中的信息披露、食品药品的强制标签与抽检、招投标的资格审查与信用记录、政府采购的履约验收，都是在把不可见的质量变成可见的凭证。政务公开与信用体系建设，直接对准的就是“数据壁垒”：各部门各存一段信息，群众被要求反复自证，“证明你妈是你妈”之所以刺目，正因为本可系统核验的事实被推回给了当事人。

在公务员考试语境里，这个概念的价值在于提供一个不诉诸“人心不古”的分析框架：把市场失灵、监管失灵、形式主义证明拆成“事前看不透”和“事后管不住”两类，再分别对症下药——前者靠强制披露、第三方认证、可退换承诺；后者靠过程留痕、随机抽查、奖惩挂钩、告知承诺加事后核查。

最常见的误解，是以为信息不对称可以被消灭。它只能被缓解，而缓解本身要花钱：体检要成本，认证会抬价，过度披露则伤及隐私与商业秘密。制度设计的目标不是信息完全，而是把差距压到交易仍能进行、且不敢轻易作假的程度。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 卖家韩某知道骡子一重载就喘 | 卖方掌握私人信息 | 质量信息天然偏向持有方 |
| 老栓只看毛色、牙口、蹄子 | 买方只能观察表面信号 | 外观与真实品质可以脱钩 |
| 草沟里走两个来回 | 验证成本高、检验不充分 | 轻载检验无法暴露重载才发作的毛病 |
| 二百八十块买进、一百一卖出 | 逆向选择下的价格与价值偏离 | 买方按看得见的质量出价，风险自担 |
| “一句话就是凭据”，事后无人担责 | 合约不完备、救济缺位 | 无可执行的承诺，说假话不受惩罚 |
| 吴老六摸蹄窝、看眼角、问平素使什么套 | 信息甄别 | 内行以专业手段压低核实成本 |
| “七天使唤不动就退钱”的黄纸 | 信号发送与质量担保 | 敢担保本身即是对质量的自我披露 |
| 卖家沉吟片刻才说“敢” | 担保成本由劣质者承担 | 好货敢承诺，次货不敢跟 |
| 老栓末了那句“吴老六一个集上能有几个” | 机制难以个人化、普遍化 | 靠个人经验补信息差，无法规模化 |
| 儿子管市场，讲明码标价、可退可换、留凭证 | 制度化压缩信息差 | 把个别买主的经验升级为普遍规则 |

## 公务员考试视角

行测常识要记准2001年诺奖与三人分工：阿克洛夫—柠檬市场，斯宾塞—信号发送，斯蒂格利茨—信息甄别；常与“劣币驱逐良币”“逆向选择”“道德风险”放在一起辨析。申论材料多为数据壁垒、“奇葩证明”、网购假货、围标串标、食品安全，可用“事前—事后”两分法立论，对策写强制信息披露、第三方认证与可退换承诺、信用记录与黑名单、告知承诺加事后核查，避免只写“加强监管”。结构化面试谈市场失灵、优化营商环境、整治形式主义证明时，先说信息握在谁手里，再说用什么机制让它显形，比空喊“提高认识”有区分度。

## 思考题

1. 老栓在草沟里试了两个来回就掏钱。若他坚持把骡子套上重车走十里地再谈价，这桩买卖会改变在哪一步？
2. 那张黄纸为什么是让卖家先回答“敢”，而不是由老栓自己写下“如有毛病，概不退货”？
3. 老赵说“一句话就是凭据”。他在集上扮演什么角色？若由他统一登记凭据并留底，他自己的生意会受什么影响？
