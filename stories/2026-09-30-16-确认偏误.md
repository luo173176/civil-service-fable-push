# 只响半边的听筒

## 寓言故事

清河镇外有条白龙河，五年淹一回。那年县里拨下修堤的钱，剩下的事只有一件：先护东岸，还是先护西岸。

副镇长宋砚管这个事。他心里早有一杆秤。他爹十九岁那年在东岸的柳树行里被水围过，抱着一根椽子泡了半宿，落下一辈子的咳。宋砚从小听这个故事，听到三十岁，认定东岸天生该先护。

他带了三个人、一只洋铁皮的听音筒去摸底。筒子原是测堤基用的，杵在地上，能听出底下有没有空腔。

东岸柳树行里，他碰上老石匠钱四。钱四说，东岸是沙底，水一泡就松；西岸是胶泥，硬。宋砚蹲下，把筒子杵进土里，听了半晌，说：“底下空。”钱四说：“你歪着拿，它自然也歪着响。”

宋砚没接话。他在台账上划了两栏，左栏写“要紧”，右栏写“待核”。钱四的名字落在右栏。

接下来十天，他走了十七户。每家问的话都一样：“东岸是不是淹得凶？”说凶的，他记进左栏，还追问一句“哪一年”；说不凶的，他记进右栏，顺口添一句“你家在西岸有亲戚吧”。真有四户是。

他还带了两张土剖面图。给东岸农户看的是东岸那张，手指按着裂缝问：“你看这儿，是不是要塌？”人家说看不准，他就把指头往缝里再按一按：“你再看这儿。”

回来开会，他把左栏从头念到尾，右栏归成一句：“另有少数意见，不足为据。”镇长问，要不要请县水文站复测一回。宋砚说不用，汛期只剩四十天，动工要紧。

堤修在东岸。那年的水早来半个月，从西岸翻进去，淹了七十多亩，六十亩正在西岸的胶泥地上。西岸的人后来才拼出一件事：当初唯一说过西岸也险的，就是被随手记进右栏的那几户。

钱四拄着拐杖上堤找他。老头子没骂人，只说：“你那筒子，从头到尾只顺着你那一头响。你拿它去听井，它就替你把你自己还回来。”

宋砚在堤上站到天黑。回家翻台账，左栏密密麻麻，右栏一共九行，八行被人用指甲掐过。他翻到最后一页，写了一行字：

我走了十七户，其实只问过一个人。

## 原来讲的是……
**概念：确认偏误**

## 概念解释

确认偏误（confirmation bias），指人在形成假设或既有信念之后，倾向于搜寻、注意、解释并记住那些与既有信念一致的信息，同时忽视、贬低或遗忘与之冲突的信息。它通常包含四个环节：选择性搜索（只去找可能支持自己的证据）、选择性解释（对含糊证据作有利于自己的解读）、选择性记忆（记住支持的、忘掉反对的）与信念固着（即使原始依据被推翻，信念仍然存活）。关键在于，偏误发生在“假设已经形成之后”，而不是形成之前。它并不否定人的推理能力，只是让推理能力转而服务于既定结论。

学术背景可以追到1960年。英国心理学家彼得·沃森（Peter Wason）设计了著名的“2-4-6任务”：他告诉被试，“2、4、6”这三个数符合某条规则（真规则是“三个数递增”），让被试不断提出新的三数组，主试只回答“符合”或“不符合”。绝大多数人提的都是“8、10、12”这类能验证自己猜想的数组，几乎没有人提“4、2、6”这类可能推翻它的数组。他们一次次拿到“符合”，却迟迟找不出真规则。1960年代末，沃森用 confirmation bias 来命名这种倾向；1979年的“沃森选择任务”进一步显示，面对E、K、4、7四张卡片和“若一面是元音，则另一面是偶数”的规则，多数人只翻可能印证规则的那张，而不去翻可能推翻它的那张。1998年，尼克森（Raymond Nickerson）在综述中把这一现象概括为“以多种面目无处不在”，并把它与信念固着、认知失调、动机性推理等研究串成一条线。最需要澄清的误解是：这不是蠢人的专利。恰恰相反，认知能力越强的人，越擅长为自己的立场搭起精巧的论证脚手架——这在实验中被称作动机性推理。

在公共管理与公务员考试语境中，这个机制直接决定决策质量。调研一旦沦为“为方案找支持”，问卷怎么设计、走访谁、座谈名单怎么拟、样本怎么筛，都会不自觉朝一个方向倾斜，“兼听则明”就会退化成“兼听则同”。学界与实务界常用的三道防线是：魔鬼代言人（devil's advocate），正式指定一个人专门挑方案的毛病，并把挑出问题算作他的业绩；红队评审，在重大决策前由另一支独立队伍重新推演一遍；预注册承诺，在调研开始之前就写下“什么样的证据会让我放弃这个方案”，签字存档，事后再对照。

现实案例至少有三个。其一是越战与“麦克纳马拉谬误”。1960年代，美国国防部长麦克纳马拉用歼敌数、投弹吨位、村庄控制率等可量化指标衡量战争进展，这些指标恰好印证了“正在取胜”；而情报系统中关于对手韧性与补给能力的相反评估，则被归入“悲观论调”边缘化。其二是2003年伊拉克情报。在“伊拉克拥有大规模杀伤性武器”的判断已经成形之后，来源可疑的线报被高度采信，核查人员“未发现证据”的报告则被解释成“他们藏得更深了”；美国参议院情报委员会2004年的报告明确指出，这是信息被用来支持既定结论。其三是柯达。1975年柯达就造出了世界上第一台数码相机，但公司长期以胶卷业务的利润数据论证“数码不值得做”，把数码团队的市场调研当成威胁而非证据，最终在2012年申请破产保护。在国内基层也常见类似情形：某地推进村庄合并前做民意征集，只走访了已签同意书的农户，把反对声音记为“个别情况”。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 宋砚父亲在东岸被水围的旧事 | 先有结论 | 情感记忆先于调查形成判断，成为后续一切取舍的标尺 |
| 台账分设“要紧”与“待核”两栏 | 选择性搜索与选择性解释 | 同一批事实被事先分栏，支持者入正册，反对者入另册 |
| 说西岸也险的四户被添上“亲戚”二字 | 动机性推理 | 不是否认对方有理，而是给对方的理找一个可以打折的理由 |
| 只给东岸农户看东岸的剖面图 | 验证而非证伪 | 提出的问题本身就只能被回答成“是”，无法产生否证信息 |
| 洋铁皮听音筒 | 被立场带偏的认知工具 | 工具越精密，越能把持有者的倾斜放大成“客观数据” |
| 钱四那句“只顺着你那一头响” | 回音壁 | 调研的每一环都传回自己的声音，听者却以为听到了外界 |
| 堤修东岸、西岸被淹 | 决策风险 | 偏误的代价不由持有偏误的人首先承担 |
| 最后一页写下的那行字 | 元认知觉察 | 对抗偏误的第一步不是更努力地找证据，而是先清点自己问过谁 |

## 公务员考试视角

行测逻辑判断里的加强/削弱题、因果论证题，本质就在考“这个证据能不能证伪结论”；常识判断也可能直接考沃森选择任务或常见认知偏差的对应关系。申论中，凡涉及调查研究、科学民主决策、重大行政决策程序、民意征集、“放管服”改革评估的材料，都可以用确认偏误作为分析工具，指出“调研对象单一”“只调研已同意者”“以量化指标替代真实成效”等问题，并给出魔鬼代言人、第三方评估、决策前预设证伪条件等对策。结构化面试里，谈“兼听则明”“防止一言堂”“如何对待不同意见”，可以先用一句话点明行为学依据，再落到具体做法，避免只讲态度不讲机制。

## 思考题

1. 宋砚走了十七户，为什么说“其实只问过一个人”？如果把他的问题改成一句，改成什么才能得到真正的新信息？
2. 钱四是最早说出“东岸沙底、西岸胶泥”的人，宋砚却把他记进右栏。在现实中，什么样的身份、语气或表达方式，会让正确的意见自动落入“待核”那一栏？
3. 如果你是镇长，在宋砚汇报之后、动工之前，你会设置哪一道程序，使得“反对意见被听见”不需要依赖宋砚本人的自觉？
