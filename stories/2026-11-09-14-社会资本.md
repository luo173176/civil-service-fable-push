# 谁去淘那口井

## 寓言故事

柳树屯的井在村子正当中。井台四块青石拼成，靠北一块刻着名字，一竖一竖，深浅不一。

规矩是老辈传下来的：谷雨淘井，一户出一个工，出不了工的，交两斗谷给下井的人家。井绳一年一换，辘轳三年上一回油，都由井首操持。井首是老韩头，谁家淘井没来，他不骂，只在青石背面记一笔。

头一年春上，村东搬来六户种菜的，挑水挑到井台边。老韩头拦了一回：打水可以，谷雨得出工。第二天六户全来了，还多带了两把锹。老韩头把他们的名字刻上正面，刻得比谁都深。

第三年，老户里开始躲。赵家说腰不好，孙家说人在城里回不来。谷雨那天下井的只剩九个人，外来户占了四个。老韩头蹲在井台上，等日头偏西，在背面记了三笔。写完把石屑吹了吹。

第五年，辘轳的轴磨偏了，摇起来咯噔咯噔响。老韩头挨家收钱，一户十五。赵家不给：井是祖上挖的，我祖上出过工，我凭什么再出？老韩头没争，自己掏钱换了轴。第二年轴又偏，他站在赵家门口站了半袋烟工夫，回来了，没再提。

井绳起了毛，一节一节地毛上来，没人换。七月里赵家小子打水，绳在半空断了，桶沉了底。捞桶得请邻村的人，系着绳子下井，花了三十。赵家媳妇在井台上骂了半宿，骂井绳，骂井首，就是不骂自己。

那年六月没下雨。井水下去三尺，桶够不着了，得有人下井淘深。下井是苦活，两个人轮着，整整一天。老韩头挨家敲门。赵家隔着门说：让那几户种菜的下去，他们一天挑八趟水。

外来户老陈听见了，说：我下。下完了，井台边给我留个位置搁桶——我种菜，一天八趟，桶没处放。

老户不干。井台就那么大。

从晌午吵到天擦黑，没吵出个结果。

秋天村里来了打井队，一家一户在院里打小机井，一户八百。赵家打了，孙家打了，六户种菜的没打。老陈还挑井水，挑了两年，水越来越浅，最后得拿绳子拴着小孩下井去舀。

井填那年，压了水泥，成了村口一块平地。青石被搬走，垫了谁家猪圈的门槛。

去年县里来人做乡愁调查，问村里老人：你们那口井，怎么废的？

老人想了半天，说：也没怎么。就是有一年淘井，喊了三遍，没人应。

**概念：社会资本**

## 概念解释

帕特南在《使民主运转起来》（1993）里，把社会网络、互惠规范与信任这三样东西合称“社会资本”，并给了一个功能性的界定：它们能够通过促进合作行为来提高社会的效率。二十年的意大利南北对比研究让他相信，北方那些合唱团、合作社、邻里互助会密密麻麻的地方，政府绩效更好、经济更有活力——不是因为那里的人更聪明或更富，而是因为那里的人更容易彼此相信，也因此更容易一起干事。

这个概念有三个关键条件，缺一不可。第一，网络必须是可重复、可参与的互动结构，而不是一次性的交易；淘井、议事、球赛、志愿队，都属于这类把人们反复拴在一起的事情。第二，规范必须是“普遍的互惠”，而不是即时对等的交换——我今天帮你，不指望你明天就还，但相信这套东西长期看对所有人都有好处。第三，信任必须是普遍化的、可以转移的：我信得过你，不是因为你是我的亲戚，而是因为我们都在这套规则里待着。三者互为因果，会滚成一个良性循环，也会滚成一个恶性循环。

学术上，这一脉的源头可以追到汉尼凡（1916）谈乡村学校社区中心，布迪厄（1980）把它当资本来谈，科尔曼（1988）用理性选择解释它如何影响教育获得，帕特南则把它推到宏观治理层面，《独自打保龄》（2000）记录了他眼中美国社区参与的衰落。福山从信任与经济发展的角度作了补充，奥斯特罗姆关于公共池塘资源自主治理的研究，处理的正是同一类问题：一群没有血缘关系的人，能不能不靠官府和 market，自己把一件共有的事管好。

帕特南还区分了两种形态。“桥接型”是跨群体的横向联结——不同行业、不同出身、不同信仰的人之间的弱关系，它拓展信息、打开机会、稀释偏见。“黏合型”是群体内部的紧密抱团——家人、同乡、宗族、小圈子，它提供情感支持与相互保险，但也容易排斥外人、形成封闭的小团体，甚至滋养任人唯亲。健康的共同体需要两种都有，而转型社会通常缺的是前者。

社会资本最要紧的经济学含义是：它决定交易与治理的成本。信任存量高的地方，合同可以写得短，审批可以少几道，纠纷不必都上法院，集体行动不必都靠罚款和督察。反过来，信任一旦缺失，什么都要靠强制、靠留痕、靠加人，治理成本成倍上升。而它又是可耗竭的：一次背信，往往要用很多年的守约才能补回来；而且耗竭常常是悄无声息的，等到要办事时才发现，喊三遍没人应。

最常见的误解，是把社会资本当成“人脉学”。真正起作用的是普遍信任与公共互惠，而不是你认识谁、能找谁办事。后一种东西在熟人社会里确实管用，但它是特殊信任，反而会削弱普遍规则——办事先找关系的地方，陌生人之间的合作成本一定高。

在公共管理与公务员考试语境里，这个概念的价值在于给出一个可操作的分析框架。费孝通讲的“差序格局”，说明中国传统社会的关系网络以己为中心、以黏合型为主，普遍信任相对薄弱；城镇化把人从熟人社会推进陌生人社会，真正要补的是桥接型社会资本。社区议事会、业主委员会、志愿服务队、行业协会、村规民约、红白理事会、“时间银行”互助养老，本质上都是在为陌生人创造重复互动的场景，把“认识”变成“信任”，把“信任”变成“合作”。反面案例同样清楚：食品安全事件、扶老人被讹的新闻，损害的不是某一家企业或某一个人，而是整个信任存量，需要长期修复。

可以对照的现实案例有两个。其一是浙江宁波等地推行的“时间银行”：低龄老人为高龄老人提供服务，服务时长存入账户，将来自己可以支取，参与者跨越了楼栋、单位和年龄，是典型的桥接型网络建设，其运转前提正是居民相信这套账目不会赖掉。其二是“枫桥经验”的当代版本——村社调解员、乡贤参事会、村民议事厅，把大量纠纷化解在诉讼之前，本质上是把存量信任转成了低成本治理。反面例子是某些地方“红黑榜”刚推出时的争议：如果上榜标准不透明，一次误判就足以把多年积累的信任折损掉。

## 隐喻对应表
| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 井台与那口井 | 共有资源与公共互动场域 | 谁都能来打水，是全村重复交往、彼此照面的物理载体，网络由此生成 |
| 谷雨淘井的规矩 | 互惠规范 | 出工或出谷，权利与义务对应，属“普遍互惠”而非即时交易 |
| 老韩头在青石背面记账 | 监督与惩罚机制 | 成本极低的社会性制裁，靠记录与名声维持规范，而非罚款强制执行 |
| 青石正面的名字 | 参与网络的可视化 | 名字刻上去意味着身份与归属，参与越深，认同越强 |
| 六户种菜的与老户 | 桥接型与黏合型 | 外来户是跨群体的新联结，老户抱团守“祖上的井”，是内部抱团与排外 |
| 赵家拒摊十五块钱 | 搭便车与信任折损 | 一次不履约没有立刻受罚，却让所有人重新估算“出工值不值”，存量开始流失 |
| 起毛的井绳与磨偏的辘轳 | 社会资本的可耗竭性 | 维护靠自觉投入，几年无人投，资产就折旧到无法使用 |
| 大旱之年下井淘深 | 集体行动困境的临界点 | 最需要合作时，恰恰是存量最少的时候，喊三遍无人应 |
| 老陈“下井可以，给我留个放桶的位置” | 参与的合理条件与信任谈判 | 愿意出力者要求可见的回报，若被拒，桥接型联结就此中断 |
| 各家打小机井 | 信任退化为私人替代方案 | 公共合作失败后，人人自费买“保险”，总成本更高，公共池彻底废弃 |
| 填井、青石垫猪圈门槛 | 社会资本存量的不可逆损失 | 载体消失后难以重建，规则记忆退化为一句“也没怎么” |

## 公务员考试视角

行测常识可能直接考人物与著作：帕特南、《使民主运转起来》《独自打保龄》，或以定义判断形式出现，正确选项必然包含“网络、规范、信任”三要素并指向合作效率，干扰项则冒充“人脉广、关系硬”。申论材料常见邻里冷漠、志愿者队伍流失、村规民约失效、人情负担沉重、诚信红黑榜等，作答时不要停在“加强宣传”，而要落到“搭场景、建组织、给回报、护信任”：先造可重复互动的载体（议事会、志愿队、协会），再让规范可预期，最后才谈得上降低治理成本。结构化面试中，“如何组织社区志愿活动”“如何化解加装电梯分歧”这类题，用得上桥接与黏合的区分：既要让不同楼栋、不同年龄的人坐到一张桌子上，也要防着几个熟人把小团体把持了议事。

## 思考题
1. 老韩头在青石背面记了三笔，为什么第五年收钱被拒之后就不记了？如果那年他把赵家的名字也刻上去，井的命运会不一样吗？
2. 老陈愿意下井，条件只是“井台边给我留个位置搁桶”，这个要求过分吗？老户拒绝的究竟是什么——是地方，还是“外来户也能提条件”这件事？
3. 县里来人问“井怎么废的”，老人答“也没怎么，就是有一年淘井，喊了三遍，没人应”。这句轻描淡写的回答里，藏着哪些被忽略的年份和选择？
