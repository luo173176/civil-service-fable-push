# 谁都没被拦住

## 寓言故事

县二中食堂的泔水桶每天早上被拖拉机拉走，夏天隔着操场都能闻到味。新校长在班子会上拍了桌子：下学期开学前，泔水必须少一半。

总务处王主任的方案很直接：抓。倒饭处挂块牌子，剩饭超过二两的扣班级量化分；再派两个学生站岗，端着盆盯着。他补了一句：“不狠不行，这帮孩子皮。”

食堂管理员老陈没吭声。他在这口灶前站了十七年，掌过勺，补过灶台，也在雪夜里一个人卸过三车白菜。散会后王主任问他意见，他说：“牌子你挂，我不拦。扣分罚款这事，得校长签字。”

校长没签。于是老陈动手了。

第一件事，他把用了十几年的搪瓷大碗换成小一号的白瓷碗——原先一碗四两，现在三两，添饭的窗口照旧开着，米饭管够。第二件事，他把馒头筐从食堂门口挪到了打菜窗口最里头，先打菜，后拿馒头。第三件事最不起眼：原先摆在第一格的红烧肉，挪到了最后一格，素菜在前，肉在后。

水果筐本来在库房里堆着，中午由一个阿姨守着发，学生排队签字。老陈把筐子直接搬到收银台边上，谁想拿谁拿，签字的簿子收进了抽屉。

这些改动做了三天，没人察觉。学生只是隐约觉得，碗浅了点，肉不像以前那样打头阵了。

开学第三周的中午，老陈蹲在泔水桶边，拿竹竿往里按了按——见底了。他绕到后门看第二只桶，只有半桶。

他让人把磅秤搬到门口，每天早晨称一次，数字用粉笔写在打饭窗口上方那块黑板上：昨天剩饭六十八斤。第二天写六十一。第三天写五十八。写了一个月，数字降到四十上下，再没上去过。

真正让王主任服气的，是另一件事。

学校办秋季运动会，动员各班报志愿者。往年做法是班主任在班里问一句“愿意的举手”，全年级举手四十七人，最后真正到场的不到二十。老陈给总务处出了个主意：报名表改印，每个人名字下面预先印好“参加”两个字，不参加的自己拿笔划掉。表格发下去，全校划掉的共十二人。运动会那天，志愿者到了三百多个。

王主任把表格翻来覆去看了半天，问：“你这是使了什么招？”

老陈说：“没使招。我把馒头挪到后面，把碗换成小的。谁想多打饭，窗口又不是不开。谁不想来，划一道就是了。”

王主任还是不明白。他只记得，那年冬天，食堂后门那两只泔水桶，头一回没装满。

老陈把磅秤搬回库房那天，说了句话：“我没拦谁，我就是把东西挪了挪。”

## 原来讲的是……

**概念：助推**

## 概念解释

这就是理查德·塞勒（Richard Thaler）与卡斯·桑斯坦（Cass Sunstein）在 2008 年合著的《助推》（*Nudge: Improving Decisions About Health, Wealth, and Happiness*）中所说的**助推**：不禁止任何选项，不显著改变经济激励，仅仅通过调整**选择架构**——默认项、排列顺序、呈现方式、提示与反馈——来引导人的行为。

要构成一次合格的助推，至少要满足几个条件。其一，**不封堵**：所有选项都还在，肉菜没被取消，添饭窗口没被关上，志愿者名额没有强制摊派。其二，**不改激励**：没有罚款，没有补贴，价格没有动，老陈拒绝的正是这条路。其三，**改变选择架构**：默认值（小碗、预印的“参加”）、排序（素菜在前、馒头在后）、摩擦成本（水果免签字）、反馈（黑板上的斤数）。其四，**退出自由**：想多打饭可以起身去添，不想参加可以拿笔划掉，退出成本几乎为零。塞勒和桑斯坦把这套立场称为“自由家长主义”——像家长一样关心结果，但保留你的选择权。

学术上，助推的根扎在卡尼曼与特沃斯基的前景理论与双系统理论里。人并不是时刻运转的理性计算器，多数日常决策由快速、直觉的系统一完成，于是**现状偏好**（不改默认）、**损失厌恶**、**可得性**与**锚定**都会悄悄左右结果。塞勒因在行为经济学上的贡献获 2017 年诺贝尔经济学奖，“助推”是他最具公共影响力的概念出口。

它在公共管理中的意义，是提供了一条介于“命令—控制”与“宣传教育”之间的第三条路：成本低、见效快、可用随机对照实验测量，且不侵蚀个人自由。2010 年英国政府在首相府内设立行为洞察团队（Behavioural Insights Team，俗称“助推小组”），此后美国、新加坡、澳大利亚、加拿大等相继设立类似机构，用于提高税款按时缴纳率、提升养老金参保与储蓄率、推动器官捐献登记、降低能源消耗。

现实案例中，最常被引用的是器官捐献：在“选择加入”（opt-in）的国家，公民需主动登记才算同意，参与率往往只有一两成；而在“默认同意”（opt-out）的国家，公民须主动声明才退出，参与率常超过九成——法律上两者都尊重个人意愿，差别只在一个默认项。英国行为洞察团队则通过改写税务催缴信函（如提示“你所在地区多数人已按时缴纳”），在几周内追回数亿英镑税款。国内的“小份菜”“半份饭”、食堂自助餐按盘计量、政务短信提醒办理时限，也属于同一逻辑。

必须强调，助推不是强制，更不是营销话术。它与“暗黑模式”（dark patterns）恰好相反：后者通过隐藏选项、制造误导性默认、增加退出难度来剥夺选择，是对助推逻辑的滥用与反讽——比如预勾选的付费订阅、藏得很深的取消入口。判断标准很简单：如果当事人知道了这个设计，会不会觉得被操纵、被欺骗？会，那它就不是助推。

## 隐喻对应表

| 故事元素 | 对应概念要素 | 说明 |
| --- | --- | --- |
| 搪瓷大碗换成小一号白瓷碗 | 默认选项的设定 | 不禁止添饭，只把默认份量改小 |
| 添饭窗口照旧开着 | 退出自由 | 想多吃可以自己起身，成本极低 |
| 馒头筐从门口挪到窗口最里头 | 选择架构中的排序 | 拿走取路径改变，选择概率随之改变 |
| 红烧肉从第一格挪到最后一格 | 呈现顺序 | 肉菜没被取消，只是不再排在首位 |
| 水果筐搬到收银台边、免签字 | 降低摩擦成本 | 少一个签字动作，行为发生率就上升 |
| 黑板上每日更新的剩饭斤数 | 反馈与提示 | 把结果可视化，本身就是一种引导 |
| 报名表预印“参加”二字 | 默认同意（opt-out） | 退出只需划一道，参与率却翻数倍 |
| 王主任主张扣分、站岗、挂罚牌 | 传统命令—控制手段 | 靠惩罚与监督，被主人公拒绝采行 |
| 校长拒绝签字 | 权力边界与合法性 | 没有法定授权，强制手段无法启动 |
| 泔水桶从装满到半桶 | 效果的可测量性 | 行为改变可以用具体指标验证 |

## 公务员考试视角

行测常识中，本概念可能以“塞勒与桑斯坦合著《助推》、2017 年诺贝尔经济学奖、行为经济学与前景理论、有限理性”等形式出现在常识判断或定义判断里，需能把“助推”与“罚款”“宣传教育”区分开。申论中，凡涉及食堂浪费、垃圾分类、医保社保参保率、电子发票与电子账单推广、节能降耗等对策题，除了写“加强宣传、严格考核”，可加一层“优化选择架构”：改默认项、调排序、减环节、给反馈。结构化面试中，常以“某地推行默认电子账单/器官捐献默认同意/单位小份菜”作综合分析题，答题要点在于既肯定其低成本高效，又点明须保留退出自由、防止操纵，切忌越界成强制，也不能沦为“暗黑模式”。

## 思考题

1. 老陈为什么坚决不肯挂那块扣分罚款的牌子？如果校长签了字，故事会怎么走？请分别从“效果”和“自由”两个角度推演结局。
2. 班主任口头问“愿意的举手”和报名表上预印“参加”，学生面对的是同一个选择，为什么结果相差数倍？差别究竟落在哪一个具体环节上？
3. 假如老陈一边把红烧肉挪到最后一格，一边悄悄把素菜价格提高一毛钱，这套做法还能叫助推吗？他的三处改动里，哪一处最经不起这种追问？
